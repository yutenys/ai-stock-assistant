## 2. 已定位的问题

### P0：推荐计划和入场许可在账本中丢失

`main.js:buildRecommendationLedgerEntry`读取 `item.tradePlan`，实际分析结果位于 `item.analysis.tradePlan`。当日7只报告股票的触发价、失效价、盈亏比全部为空，`researchEntryEligible`全部为false。

同函数重新调用 `classifyRecommendationRole`，传入原始analysis；分类器实际需要标准化的 `trendBroken/boxStable/volumeCompressed/supportIntact`。分类器也不使用传入的入场许可。导致已经计算过的角色/许可被重新降为“趋势观察/watch”。

当前收盘A候选5只都有嵌套计划，但4只 `entryAssessment.allowed=false`。其中3只的 `strategyDecision.status`仍为strict；建发股份allowed=true又会在账本层丢掉计划。这里混淆了“筛选分数高”“形态角色”“此刻可入场”三个概念。

09-29实施状态文档宣称计划冻结已落地；本次检查证明调用链尚未一致，必须补端到端契约测试，不能只验单个函数。

### P1：名义盈亏比不对应实际买点

`buildTradePlan`以假设低吸区中值计算风险，以历史区间高点计算收益，却同时展示低吸、回踩、突破三种买入步骤。历史高点不是已经确认可达的目标。

本次收盘快照例子：

- 爱美客：显示盈亏比13.20；突破确认95.72，失效90.54，第一目标97.16。按该突破路径计算的第一目标收益/风险约0.28，尚未扣费用。
- 建发股份：显示盈亏比10.42；突破确认8.80，失效8.42，第一目标9.06。对应约0.68，尚未扣费用。

这不证明股票必然下跌，但证明当前“高盈亏比”不能作为该突破路径可入场的证据。

### P1：强势发现与可入场筛选混用

`momentumRecommendationDecision`可因当日涨幅较高、接近日高和成交额达标入选。爆量/涨停多数是后加“不追涨”的观察说明，而非形成独立的等待回踩名单。

结果是B列表持续展示已明显上涨的股票，却缺少可追踪的首次回踩触发、撤销、失效事件。当天B的6只全部涨幅超过4%，其中2只已经涨停；这是需要验证的入场位置风险，不应用增加数量解决。

## 3. 目标决策链

```text
冻结输入及每字段来源/时间
  -> 数据有效性、交易日与风险检查
  -> 市场状态及其变化
  -> 板块回流/扩散/拥挤/退潮
  -> A结构候选 / B强势观察
  -> 对应买点的触发、失效、净风险收益
  -> 一份入场决策
  -> 推荐 / 详情 / 收藏当前分析 / 不可变发布账本
  -> 全样本观察评价 + 可核验执行评价
```

### 3.1 唯一决策契约

复用现有 `entryAssessment`、`analysis.tradePlan`、`roleAssessment`和scoreCard，不另起评分系统。发布前只标准化一次：

- `primaryRole`仅描述形态，不产生买入许可；角色识别缺信息为unknown，不自动趋势健康。
- `entryPermission`明确 `watch/armed/allowed/blocked/expired`；高分或研究命中不能覆盖blocked。
- `setupType`区分低吸、首次回踩、突破确认；一份活动计划只对应一个主入场路径，其他路径明确为备选。
- 冻结 `signalId/episodeId/modelVersion/publishedAt/inputCutoffAt`、行情/日线/资金/资讯各自时间、触发价、失效价、目标证据、许可理由及最早买卖日期。
- 区分当日大单净额和3/5/10日汇总字段，带 `window/source/estimated/stale`；不能把10日资金当成“当前实时净流入”。
- UI、详情、收藏当前评分、账本读取同一个快照；收藏加入时快照保持不变。
- 旧记录缺计划必须留空并标记“历史发布缺字段”，不使用今天计划回填昨天信号。

### 3.2 A：结构合理，再判断价格是否值得入场

- 保留底部结构、横盘蓄势、健康回踩、突破确认分类，不以“涨得少”直接认定滞涨补涨。
- “底部”须相对于可用20/60/120日价格位置、既有涨幅和支撑位置给出证据。像已有大幅区间上涨的样本，不因均线粘合就继续标底部；可标趋势整理，缺长历史则待确认。
- 先排除结构失效、关键历史过期、真实资金背离和无法定义风险边界，再比较板块扩散与个股相对强弱。
- 等待回踩的候选可以展示，不计为已满足入场；首次触发要独立记录当时买点，不能沿用更低的最早观察价格制造收益。

### 3.3 B：强势发现与首次回踩分开

保留方案A/B左右切换；B内部增加两个明确分组，不增加第三套主推荐：

1. **强势观察：** 记录资金前排、当日转强、涨停和加速股；展示不可追原因、等待区域和失效条件。
2. **回踩待触发/已触发：** 前次突破有真实时间证据；首次回踩未破坏结构，量能收缩，板块去龙头后仍有承接；触发时再次核对当日个股资金及价格。

突破放量继续使用1.5–4倍的明确口径；回踩缩量不得套用突破量比门槛。盘中累计量和完整日均量不可直接比较，缺同时间段基线则量能待核验。

高开越过计划价、再次爆量、支撑破坏、板块退潮、计划过期均撤销入场许可，保留原观察记录及撤销原因。不能为了扩大推荐数量把B观察升级为allowed。

### 3.4 资金轮动：判断扩散和持续，而非只看当日净额排行

- 成分统计同时保留原始口径和常规交易成分口径；对上市初期无正常涨跌幅限制等异常样本单列，不用其证明成熟板块普涨。依据当时上市/限价资料，不仅靠名称是否有N。
- 保留供应商指数涨幅，另列有效成分数、中位数、上涨比例、站上均线比例、去最大贡献股后的上涨比例和净额；原始数据不删改。
- 小板块不强行伪造置信度。样本数、成员覆盖、数据新鲜度共同决定“可确认扩散/小样本待确认”；2只上涨不能等价于50只普涨。
- 区分当日转入、持续扩散、拥挤分化、退潮；5日仍负而今日转正仅称“回流试探”，不一律否决，也不自动判持续流入。
- 3/5/10日重叠窗口不相加。允许展示 `5日-当日`、`10日-5日`，但注明前后窗口，不能称逐日连续流入。
- 比较至少两份不同、同来源、时间间隔合理的盘中快照；行情缓存重复不构成持续确认。累计净额增量只在同源同口径、无重置时比较，不能同跨源数值相减。
- 医药行业与创新药/CRO等重叠概念保留各自视图，风险聚合按股票成员去重；共同主题集中度与行业分散度分开展示。
- 候选排序优先风险可控和可执行，再比较扩散、资金改善与行业相对强度；绝对净额不能天然偏爱大市值。

### 3.5 大盘、消息和美股作为有时间边界的上下文

- 大盘既保存当前状态，也保存广度、涨跌停、等权表现和板块扩散的变化。今日55.15%降至47.61%的广度衰减必须显式显示，而不是一直展示同一个“震荡轮动”。
- 大盘风险释放仍优先于局部热点；普通轮动降温先限制追高和总风险，不能仅凭一次广度下降就清空全部合理候选。新增变化规则先影子验证。
- 资讯区分有依据催化、一般相关、风险、缺失；缺资讯不加利好分。只使用发布时间不晚于决策时点的原文链接，去重转载，记录事件有效期。
- 美股三指数只作全局风险背景。有真实行业映射和可核验行情时再做科技/医药等方向修正；没有则明确缺失，不用纳指替代所有美股行业。
- 重生成报告可以补充“盘后信息”，不得把盘后新闻倒灌到早盘推荐理由。

### 3.6 买点、退出和T+1必须共同设计

每个setup使用自己的预计成交价、最近有依据的目标、结构失效价；没有可靠目标则净盈亏比unknown。展示第一目标风险收益与后续目标情景，不能用最高远期目标批准入场。

```text
净目标收益 = 目标价 - 预计成交价 - 买卖费用与滑点
压力风险 = 预计成交价 - 压力退出价 + 买卖费用与滑点
净风险收益 = 净目标收益 / 压力风险
```

压力退出价考虑T+1隔夜跳空，不假设触及止损即能成交。分批建仓以各笔成交和T+1可卖数量重算，不能整仓按最低低吸价评估。退出包括结构失效、资金背离、时间止损和盈利回撤保护，全部留痕；跌停/停牌未成交继续计风险敞口。

9月30日盘中买入最早10月8日卖出；9月30日盘后信号最早10月8日买、10月9日卖。10月1–7日休市，10月8日开市，依据[上交所2026年休市安排](https://www.sse.com.cn/disclosure/dealinstruc/closed/c/c_20251222_10802510.shtml)。

跨长假显示无法卖出的自然日风险；假期前盘中触发不得无条件沿用至节后。下一开市日必须刷新价格、公司风险、资金和消息重新确认，不能把计划日期改为交易日后就认为风险处理完成。

## 4. 报告评价重构

### 4.1 三类表现并存，不删除亏损观察

| 分栏 | 入选依据 | 价格基准 | 能否称实际收益 |
| --- | --- | --- | --- |
| 发布后价格观察 | 所有真实发布episode | 对应发布时有效报价 | 否 |
| 触发后价格观察 | 真实发生的触发事件 | 触发时有效报价 | 否 |
| 可核验执行评价 | 许可、触发、可成交和T+1证据完整 | 有依据的成交/保守成交代理 | 代理与真实模拟成交再分开 |

总表覆盖全天首次发布episode；检查点表仅为分时切片。去重跨A/B时按实际发布时间，而非数组顺序；A/B各自统计但合计按唯一股票或共同风险说明。一个episode重复刷新不增加独立样本；观察转触发保留事件链。

涨停买不到、未触发、失效、缺证据、未到期分别列数量。0%观察不能冒充成交保本；unknown不按0收益参与均值。历史27只跟踪存在选样和不同持有期，只保留为追踪列表，不充当固定窗胜率。

### 4.2 检查点与数据质量

- 10:00/11:30/14:30逐项显示是否覆盖、最近先前批次、发布时间、行情年龄和缺失原因。严格时效规则不静默放宽。
- 124秒/151秒的旧快照可以作为明确标注的“最近先前观察”，单独展示；不混入严格检查点统计，不取检查点之后发布的批次补位。
- 全日主评价从实际发布事件生成，不依赖2分钟检查点是否碰巧命中。程序未运行的时段标未观测，禁止补造信号。
- 当前大盘收盘总结与各推荐时点上下文分别显示；标题明确“收盘最新观察名单”或“09:59发布后表现”。
- 收盘价必须交易日一致且确认为收盘；企业行动、复权基础和价格基准有差异时单列待核验。
- 同时展示覆盖率、成熟样本数、缺失比例、均值、中位数、正收益比例、尾部损失和持有窗；比较同期同窗口行业/市场基准，不能拿09:59后的个股收益直接减全天指数涨幅当超额。
- 红涨绿跌、0中性；缺失不着色为涨跌。报告重生成保留修订号、输入哈希和缺失清单，浏览器打开使用同一修订。

## 6. 效果评价与停止条件

- 保留既有前瞻最低门槛：冻结版本后至少20个新交易日，A的20交易日窗、B的5交易日窗各至少30个成熟且有可成交证据的episode。改变决策规则的实验重新计时，不能借用已看过的09-30样本填门槛。
- 除平均收益，必须报告中位数、费后收益、同窗口超额、胜率及不确定性、亏损尾部、资金曲线回撤、暴露和换手。样本不足只报告观察，不输出“优化有效”。
- 同一批事前冻结市场/股票输入上做配对对照；缺失样本单列。新规则少交易时还需比较相同资金、现金占用和风险敞口，不能只比剩余个股均值。
- 去掉最佳一笔/最佳一天/最强题材后的结果也要报告，防止收益只由少数异常值支撑；不据此删除原始样本。
- 参数在新样本到来前冻结；多组实验完整披露，不选择最好的一组直接上线。资金轮动和消息新增条件先消融，确认不是重复奖励同一证据。
- 达到最低数量仍不足以自动推广；只有样本外收益与风险、执行可行性共同支持才人工批准。若尾部损失扩大、时点泄漏、可成交证据缺失或改善仅来自删样本，停止推广。

**本轮优先成果不是更多推荐，而是：报告覆盖真实、入场状态一致、风险收益与买点一致、资金轮动能区分试探和扩散。** 完成这些基础修复后，才能判断新增规则是否真正降低亏损，而不是让页面上的收益更好看。
