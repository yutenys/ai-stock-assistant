# 2026-10-09 题材容量与60分钟买点实施记录

对应设计：`2026-10-09-theme-capacity-and-60m-entry-plan.md`。本记录只说明代码和验证状态，不表示策略收益已被证明。

## 已实现

- 60分钟腾讯K线接入现有图表IPC；归一化开收时刻、手/股单位、不复权口径、未完成末根、缺根/重复/乱序与源时间问题。只用完整同口径K线识别滚动箱体、1.5至4倍同钟量能离开、首次回踩、冻结确认价/失效价；旧失效箱体不遮住后来形成的新箱体。
- 推荐候选每轨前8只及已有60分钟计划按需获取小时线；首次回踩确认后才读取5分钟线。60分钟计划使用独立版本和计划ID，独立于原日线/首次回踩正式计划；仅在后续完整5分钟K线、实时行情、风险/市场/收益风险比公共条件满足时产生影子许可。同一证据哈希不因次日刷新重建计划。推荐卡片、普通个股详情与图表分别显示结构阶段、价格线、当前许可和T+1日期。
- 研究账户新增科创板买入至少200股、超过200股可按1股递增及不足200股剩余持仓整笔卖出规则；旧100股板块逻辑保留。
- 修复全市场任务相关的内存风险：RPS横截面每周期只排序一次；全市场结果每100只持久化一批，减少重复读取/写入大JSON。大盘分析Worker每轮结束释放，并保留异常监听，防止后续Worker异常成为主进程未捕获错误。线程失败会在任务状态及顶部提示显示首行原因；失败进度保留，可恢复任务。
- `lib/theme-entry.js` 已有独立、可测试的题材成员、容量股、广度与资金证据计算。缺数据返回unknown，不按0或确认处理。

## 尚未完成 / 证据不足

- **P1应用接入**：现有本地历史大多只有OHLCV，未保存前一交易日以前20日逐日真实成交额。因此不能按设计冻结真实容量股集合。公开板块资金也未必具备两次相隔15分钟、同源同成员的独立源时点。题材证据模块尚未接到实时推荐/报告；不能称题材资金与容量“双重确认”。
- **P3/P4**：推荐卡片与收盘报告尚未完整展示题材证据、60分钟影子计划兑现；H5-H7预注册清单、独立回放和前瞻统计尚未接入。旧H1-H4与正式v26未修改；不声称新买点改善收益。
- **性能实测**：5922条本地研究结果的RPS重新计算约25ms、额外堆约5MB；这是局部计算测试，不是完整Electron任务的内存上限证明。UI用模拟的Worker OOM消息验证任务失败提示、恢复按钮和输入框仍可用；尚需在实际大规模任务上观察峰值内存和长时间稳定性。
