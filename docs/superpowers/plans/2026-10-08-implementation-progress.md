## 运行入口

```powershell
npm run audit:strategy -- --from 2026-09-09 --to 2026-10-08 --root .
npm run replay:experiments -- --input cache/strategy-audits/<runId>/replay-input.json --out cache/<new-output>.json
```

`replay-input.json`仅在存在冻结实验清单且截至日期不早于冻结日时导出。收盘报告也会在评价线程内读取新账本的影子输入回放。缺失历史限价、停牌状态、最终OHLCV、产业主题或有效触发时记录unknown/未成交，不推断买入。

实验基线是统一资金下的冻结结构止损/第一目标退出对照，**不是原始v26全部历史退出行为的重建**；原始v26发布账本仍保留。A/B共享交易的路线归属净值只能作诊断，不能相加。小于足够分批数量的持仓按100股整数手约束，分批比例可能改变，不能按30/30/40碎股模拟。
