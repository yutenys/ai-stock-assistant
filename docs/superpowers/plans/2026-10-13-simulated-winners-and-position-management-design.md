> 2026-10-13，修订设计稿，未实施。范围：从两只早期大盘推荐的持仓路径、量能、公司事件及资金证据缺口，改进通用候选发现、入场确认、持续跟踪和推荐降级。持仓管理是验证闭环，不是本次唯一重点。

## 2. 盈利如何形成

### 2.1 同一买入日，不同价格路径

以买入日为D0，D+n为之后第n个实际行情交易日；截至10-12共有37根持有期日线，含买入日。下表为当日收盘相对模拟成本的观察收益，未扣费，不是按最优价成交的回测。

| --- | ---: | ---: |

| D1，08-14 | -4.40% | +5.16% |

| D10，08-27 | -6.19% | +10.77% |

| D30，09-24 | +11.28% | +46.35% |
| 10-12收盘 | +33.43% | +38.88% |

**吉华集团：早期买点并不理想，后续形成上涨趋势。**

- 买入前08-12收盘7.21，MA5/10/20/30约6.90/6.76/6.45/6.35，短中期均线向上；过去20日已涨16.29%，当日量为此前20日均量约1.28倍，不满足用户设定的1.5至4倍放量确认。
- 买入后先下跌，08-25收盘6.55，较成本-9.90%；买入日之后的最低价6.40，较成本-11.97%。两次收盘亏损超过8%，不能当作低风险顺畅上涨案例。
- 09-01才首次收盘回到成本之上，之后又经历震荡。持有期最大收盘峰谷回撤约10.17%，并非持有期间没有风险。
- 所以要研究“初始信号过早”“结构失效后重新转强的独立机会”，不能把最终+42%作为放宽止损的理由。

**光洋股份：修复转强后获得主要利润，近期已经明显回吐。**

- 买入前08-12收盘11.33，MA5/10/20约10.74/10.37/9.99，但MA60约12.48；短期修复和长期趋势偏弱同时存在。过去60日约-27.88%，不是标准全均线多头。
- 买入前一日同口径日量比约1.70，符合放量区间；但没有当时盘中资金、消息和触发快照，不能认定符合今日全部正式门禁。
- D5仍有亏损，D20才达到约+46%；09-30最高收盘17.43，对应浮盈4,952元。
- 到10:25:09的15.02元，较这个收盘峰值回撤13.83%，浮盈回吐1,928元，相当于曾有收盘浮盈的38.93%。这是持仓保护问题，不能因仍赚33.63%就显示低风险。
- 最高日内价17.90只用于观察价格路径；不能假定800股能够在该最高价全部卖出。

### 2.2 原有退出规则的取舍

旧保存分析都提到“连续两日收盘跌破MA20应降低仓位”。用本次读取的历史日线计算每天自己的MA20，而不是拿今天MA20倒推过去：

| 规则首次成立 | 吉华集团 | 光洋股份 |
| --- | --- | --- |
| 连续两日收盘跌破当日MA20 | 08-24 | 10-09 |
| 下一交易日开盘价 | 08-25：6.70 | 10-12：15.66 |
| 假设当时全仓退出的毛收益 | -7.84% | +39.32% |

这是**规则取舍的事后情景检查**，不是已发生交易，也不是完整回测；旧文本只说降低仓位，没有约定全仓退出比例，表中全仓是假设。尚未核验开盘成交量、滑点、费用和公司行动，不记录为已实现收益。

同一规则可能保住光洋部分利润，却错过吉华后续上涨。因此不能设计成“亏了继续等、赚了再选最佳卖点”。正确方向是允许旧计划结束，并在未来出现新的、当时可核验的趋势结构时重新建立计划；必须同时评价重新买入失败、交易成本和错过上涨的代价。

## 4. 已定位的产品与代码问题

| 问题 | 证据 | 最小修复方向 |

| 缺报价可能伪装零盈亏 | `portfolioMetrics`无lastPrice时回退成本价 | 可显示成本，但市值/浮盈必须标待估值，不能显示行情已刷新或0收益 |
| 持仓风险忽视利润回撤 | `portfolioRiskAssessment`主要看失效价、contextRisks和亏损8%，没有峰值收益/回吐；仅检查analysis.tradeDate是否存在 | 增加数据时效、当前结构、浮盈回撤三个独立维度 |
| 本地昨日K线仍未完成 | 两文件10-12保留14:17的9.60/15.63且isFinal=false，而正式收盘为9.70/15.61 | 完整日线替代同日临时条，保留证据与版本，不能将临时条当收盘 |
| 来源被误作行业 | 两持仓sector仍为“线上搜索” | sourceType与实际行业分字段；未知行业明确未知 |
| 发现来源与下单方式混淆 | 用户确认早期大盘推荐；两笔旧成交没有entrySnapshot/plan/strategy/version | 记录用户确认的推荐来源；执行方式为旧手工模拟，原发布版本/计划缺失，不归为当前v26成果 |

当前代码的手工模拟已有T+1数量锁，研究账户另有费用与批次模型；不重复建账户系统，不把旧手工记录强制迁移到研究账户。

## 5. 方案选择

| 方案 | 优点 | 代价与结论 |
| --- | --- | --- |
| 复制赢家特征、统一放宽止损 | 实现简单 | 只看两个赢家，掩盖其余亏损和早期不利路径，不采用 |
| 达到固定盈利百分比立即止盈 | 容易执行 | 容易截断吉华后续趋势，未利用结构信息，不作默认策略 |
| **事件持续跟踪 + 结构分阶段推荐 + 资金/市场确认 + 失效降级** | 区分发现、入场和持有，兼顾修复机会与追高风险 | 复用现有事件、A/B、计划和实验模块；数据修复先行，新增策略影子验证，采用 |

不增加“吉华模式”“光洋模式”白名单，不因单票成功新增独立评分体系。下述策略规则先作研究设计，不改正式许可。

## 6. 设计一：统一盈亏、时点与持仓分析

### 6.1 三份信息分开

1. `entrySnapshot`：原始买入时间、价格、策略/计划/来源版本，创建后不被刷新覆盖。旧数据缺失就缺失。来源补证独立记录为 `originEvidence`：`sourceType=market-recommendation`、`evidenceLevel=user-confirmed`、`confirmedAt`及说明；实际发布事件ID、时间、版本仍可为空，不能伪造到原成交快照中。
2. `currentQuote`：price、tradeDate、quoteObservedAt、fetchedAt、source、status；决定当前估值。
3. `currentPositionAssessment`：日线截止日、analysisAsOf、输入报价引用、资金/公告/市场证据状态、结构与持仓风险、失效条件。只保存紧凑结果和引用，不嵌入全量历史及新闻。

沿用当前portfolio结构做兼容新增；不改已有数量、成本和成交流水。未知时间的旧分析只作为历史资料，不通过给它补当前时间冒充新分析。

持仓刷新先更新报价/盈亏，再以现有并发限制获取分析。提示分别为“报价已更新、分析更新中”“报价已更新、分析部分失败”，不能让新价格配旧分析却显示全部成功。同一股票只做一次分析；过时请求完成不得覆盖较新的结果，切换视图不等待大盘全量扫描。

### 6.2 盈亏与回吐定义

```text
remainingCost = quantity * costPrice
marketValue = quantity * validCurrentPrice
unrealizedPnl = marketValue - remainingCost
unrealizedPct = unrealizedPnl / remainingCost
totalPnl = realizedPnl + unrealizedPnl
priceDrawdownFromClosePeak = min(0, currentPrice / peakFinalClose - 1)
```

旧手工账户继续明确不含费用；研究账户使用其费用/分红账本，避免重复扣费。无有效报价时unrealizedPnl为unknown，不用成本价兜成0。

固定数量、无加减仓区间可显示：

```text
peakCloseProfit = max(0, (peakFinalClose - costPrice) * quantity)
profitGiveback = max(0, peakCloseProfit - unrealizedPnl)
givebackShare = profitGiveback / peakCloseProfit  # 仅peakCloseProfit > 0
```

峰值收盘与峰值盘中分开，均非可以保证兑现的利润。当前价格创新高时回吐为0，不显示负回吐；零/负峰值利润不计算回吐比例，利润转亏时比例可以超过100%，不悄悄截断。

加减仓后不能把原大仓位峰值利润与当前小仓位浮盈直接相减。旧手工账户按数量稳定区间评价，跨区间回吐标不可比；研究账户按lots及含已实现收益的独立序列评价。收盘价格优先使用已结束交易日完整同源日线，复权口径不明则暂停跨期价格路径计算。

## 7. 设计二：用持仓阶段管理风险，而不是只看赚亏

沿用计划状态，增加持仓诊断展示，不另建交易引擎：

| 阶段 | 判定重点 | 系统输出 |
| --- | --- | --- |
| 证据待补 | 分析过期、价格/资金时点冲突、原计划缺失 | 显示缺口，不输出“安全持有” |
| 初始验证 | 原计划尚未失效、交易日与成本确定 | 原失效线及原期限，不因亏损放宽 |
| 趋势延续 | 最新完整K线支持原路径、资金/市场证据未出现有效否定 | 持仓跟踪；与“现在可新买”分开 |
| 利润保护观察 | 已有浮盈，出现价格峰值回撤或短期结构走弱 | 显示回吐金额/比例和确认条件，不仅标亏损预警 |
| 退出复核 / 待执行 | 冻结规则满足、且可卖数量与交易会话已核验 | 明确触发时点与可执行数量，无法卖出保留风险 |
| 已结束、重新观察 | 旧仓/计划已结束 | 新结构用新plan评估，不能复活旧信号或隐藏旧亏损 |

当前两只的示例输出：吉华为“趋势延续、价格偏离较大，观察利润保护”；光洋为“短期转弱、浮盈回吐明显，优先退出条件复核”。旧仓原计划缺失，不能自动发出按原策略强制卖出的命令。

### 7.1 最小研究规则

- 不新增拍脑袋的固定30%回吐卖出门槛；金额/比例先作为诊断指标。
- 有冻结原计划时优先复用其失效、分批目标和持有期限。未记录期限的旧仓不因已持37根K线就推定超期。
- 退出研究作为独立辅助对照，比较“原始买入后持有观察基线”与“连续两次完整收盘跌破当日MA20后，下一合法时段退出”。全仓退出是实验的明确规则，不称为旧手工账户原有执行规则。第8节推荐实验固定同一退出规则，不能同时调整买入与卖出再把改善归给选股。
- 该实验允许亏损退出；不能等股票盈利才开启回撤检查。是否增加分批退出留到本轮结果后另注册，避免同时优化比例、均线、ATR倍数导致无法归因。
- 日内跌破、当日资金净额、最新消息为风险补充，不用未完成日K提前确认收盘规则；重大核验风险可按现有风控独立阻止新买入。
- T+1、停牌、涨跌停、交易时段、手续费、滑点、成交量约束沿用现有研究账户。触发退出不等于成交；当天新买的部分不能T+0卖出，无法卖出时继续计真实风险。

## 8. 核心设计：从单次选股升级为可核验的机会跟踪

### 8.1 共用流程，不增加第三套推荐榜

```text
全市场候选 + 有效公司事件 + 板块轮动
  -> 建立/更新观察episode（保留首次发现与历史失败）
  -> 判定结构：修复观察 / 趋势蓄势 / 确认待触发 / 延续 / 衰减
  -> 核验真实资金、市场环境、公司风险与买点空间
  -> 现有A/B分层输出：可执行候选 / 确认观察 / 市场观察
  -> 新证据更新：升级、继续、失效、结束或建立独立新计划
  -> 冻结发布事件与后续表现，反馈至独立研究，不直接改权重
```

沿用现有A侧蓄势/回踩、B侧强势首次回踩/再次转强。修复型先进入A观察，不把所有反弹加一个“低吸”名称就允许入场；只有满足B原有资金、结构及交易条件才进入B。相同股票可有不同计划，但组合按代码合并敞口，报告保留不同发布事件。

周期标签按计划冻结，不依据事后赚得多修改。两只本次持有37根日线只是实际持续时间，不能反推旧推荐本来就是中长线。已有浮盈和较低成本不提高新买入优先级。

### 8.2 公司事件：保留有效背景，不重复制造利好

复用现有 `news-event-lifecycle`，不另做一套新闻评分：

| 事件状态 | 处理 |
| --- | --- |
| 预期形成 | 预告/项目进展进入观察理由，保存原文及首次公开时间；不当作实际业绩 |
| 进展验证 | 并购完成、订单执行等更新原事件；分别保留业务变化与利润尚未证明 |
| 兑现核对 | 正式财报比较预告与实际，分析扣非、现金流及非经常损益，不只看归母增长 |
| 反证或失效 | 取消、延期、减值、业绩落空等更新风险并降级关联候选，保留原利好历史 |
| 待复核背景 | 长期未有新进展或获取失败，不再给“最新消息加分”；背景可以展示，置信状态必须显示 |

新闻新鲜度与事件有效性分离：旧业绩预告不应几天后从观察理由完全消失，但重复转载也不能刷新事件时间或重复加分。有效期、复核时间与失效条件沿用现有事件规则；持久保留原文不等于永久有效。

吉华以07-15预告到08-28正式财报作为事件链测试；光洋以08-08收购完成与08-29财务质量弱项作为正反证并存测试。事件日期早于买入，不代表历史引擎当时看到；回放须区分 `publicAt`、`firstObservedAt`、`decisionAt`，事后补采数据只进“公开证据重建”层。

### 8.3 结构判定：不漏修复，也不把下跌叫洗盘

| 状态 | 必须解释的证据 | 推荐动作 |
| --- | --- | --- |
| 修复观察 | 价格相对MA5/10/20/30/60、各线方向、前低/阻力、前一段跌幅；结构改善仍未等于趋势反转 | 保留候选，列清未修复项，不能因低于MA60永久消失，也不因此放松正式入场 |
| 趋势蓄势 | 已确认支撑和箱体、回撤深度、量能收缩、主题及资金证据 | 沿用现有蓄势/回踩识别；缺真实资金只写量价观察，不写吸筹已确认 |
| 确认待触发 | 有来源的阻力/支撑、结构改善、对应路线量能条件、明确失效线 | 检查可行入场区间、成本后风险收益、隔夜风险，未齐仍观察 |
| 趋势延续 | 新高或支撑上移，并且未出现结构/资金/事件否定 | 持仓跟踪与新买许可分开；偏离大或目标空间不足阻止追入 |
| 衰减 / 失效 | 跌回已确认突破区、支撑失效、价格与资金背离或事件反证 | 降级/结束当前计划，保留观察历史，不能让旧高分覆盖新风险 |

具体原则：

1. 价格位置与均线方向同时检查。光洋10-12的MA20仍上升但价格已跌破，不能仅凭均线向上输出趋势健康；吉华08-25缩量跌破MA20也不能自动标洗盘。
2. 放量突破沿用1.5至4倍要求，但这是路线条件之一，不是充分条件。完整日量比与盘口量比各用各自口径/门槛，字段附窗口和单位；无同时间基准时不把盘中累计量除全天均量当确认量比。
3. 缩量回踩走回踩路线，不强求1.5倍；须同时有已确认支撑、未失效结构与后续触发。成交清淡也可缩量，不代表抛压已经充分释放。
4. 当前数据不能证明吸筹/洗盘时不显示该肯定标签。不能因未来涨了而把之前回撤改名为洗盘；允许“价量修复观察，资金待补”。
5. 不为迎合两个样本改变全局MA60门禁。先在观察层保留不同结构，正式许可沿用原路线；任何门禁变更必须单独注册，不能夹在召回改进里隐式放松。
6. 价格落回原突破区要重新验证，不沿用“已突破”。吉华09-01符合日量区间、09-02又落回7.43以下，是突破失败检测样本，不是保证买入获利的样本。

### 8.4 资金：按窗口变化识别修复，不凭单日正数定性

复用既有3/5/10日及逐日资金字段，按交易日、来源、股票/板块范围对齐。每次输出 `source / asOf / coverage / status / evidenceRefs`；缺失是unknown，不是0流入或自动通过。

- 逐日数据齐全：比较近期与之前等长窗口、净流入参与天数、净占比及价格响应；这些是大单统计代理，不证明机构身份。
- 只有真实5日/10日汇总：若同源、同截止日、同算法且窗口嵌套，才可用 `前5日净额 = 10日净额 - 5日净额`。不从汇总推导连续流入天数，不将3/5/10日相加。
- 5日仍负但较前5日流出减弱，仅标“流出减弱”；转正后也需既有独立快照、板块广度与结构确认，不能当天净额翻红就标持续增仓。
- 股价上涨、阶段资金支持且板块扩散：提升同状态观察优先级；股价上涨但资金转弱：提示分歧；股价走弱而单日净入：等待价格响应，不输出“有承接即可入场”。
- 真实资金源冲突、过期或只有成交量代理时，正式需要资金确认的路线继续阻塞。用扩大有效候选覆盖解决数量问题，不用数据缺失放水。

这些状态必须附原始窗口读数及变化，不再只给一个“资金分”。本次两个历史案例资金缺失，因此上述状态没有被历史验证，不能在案例表里填“吸筹成功”。

### 8.5 板块、大盘、海外：确认环境，防止循环自证

承接10-12文档的“单日回流 / 修复确认 / 持续扩散 / 退潮 / 未知”：

- 用当时有效成员、去前三贡献后的广度、容量股与梯队关系、跨日资金变化核验轮动。候选自身不参与为自己生成的板块确认，不能一只股大涨就证明整个板块共振。
- 吉华染料业务、光洋轴承及并购后的电子业务分别保存实际业务关系及生效时间，不用“线上搜索”当行业，也不直接套用今天概念成员倒推8月。
- 大盘广度、涨跌停结构、风险偏好与主题表现应是相同时点。市场不允许新开仓时，可继续展示观察候选，不发许可。
- 美股/海外信息仅取决策前已公开数据，并核对行业或业务关联；美国下一收盘、晚到消息不能倒灌A股当日决策。时区、交易日、数据新鲜度分别保存；没有映射证据不机械加扣分。
- 正面事件、强势板块、资金正数不能抵消公司已核验重大风险、不可成交、目标空间不足或账户风险预算超限。

本轮未恢复两股持有期间每个转折点的板块/美股快照，不能把这些因素写成已证实的上涨原因；实施时作为前瞻采集和验证项。

### 8.6 持续跟踪与重新发现

复用现有episode/计划账本，不建无限历史扫描任务。活跃候选按当前任务预算增量更新；新公告、完整日K、真实资金新窗口或风险变更才重新评估相关证据。报价变化可更新估值，但不会每tick重复拉取全量新闻与历史。

| 事件 | 状态与记录 |
| --- | --- |
| 首次发现 | 冻结发现时间、来源、观察价格和当前理由，生成或关联episode |
| 暂未触发 | 保持观察，列缺口；不每天重置首次发现价来美化表现 |
| 支撑/计划失效 | 记录失效时点及原因，撤销当前许可；长期事件背景可保留，不复活旧计划 |
| 后续新结构成立 | 创建新planId，关联旧episode/失效原因；沿用现金、T+1、敞口约束，不当天机械买回 |
| 事件结束或过期 | 按现有生命周期退出活跃集合，保留研究记录，避免永久占据推荐名额 |

首次发现、首次许可、实际触发、模拟成交四个时点分别显示。吉华的早期发现价值和初始买点回撤都应保留；光洋的修复机会和后来追高/衰减风险也应并列，而不是只记最后盈利。

### 8.7 最小实现与冻结对照

**不修改正式权重来拟合两只股票。** 先修复时点、归因、过期分析，再将“有效事件支撑的候选持续跟踪”作为一个新增影子实验，叠加于10-12设计的固定基线。原计划门禁、仓位预算、退出规则、费用、滑点、展示数量上限在两组保持一致。

- 对照组：冻结基线及原候选更新方式。
- 实验组：保留有有效事件/既有合格结构的观察候选，跨日等待原门禁满足；新事件或结构反证可降级，不因为昨天没触发就无条件丢弃，也不因为昨天高分就永久保留。
- 不同时改资金门槛、突破阈值、均线门禁和退出规则。MA60修复路线的正式许可研究若有必要，后续独立注册；本轮只改善观察召回与连续性。
- 两组共用当天全市场范围和采集预算；实验新增候选占用预算应计入成本，不能让一组多请求十倍数据再归因算法优秀。
- 既有退出对照单独评价，不能将其减少的回撤记为本轮选股改进。

补存字段以现有结构可推导为先：`originEvidence`、候选关联的 `eventIds`、`structureState`、各维度 `asOf/status`、`lastTransitionReason`、`experimentVersion`。观察价、计划价、成交价继续独立；不在持仓对象复制整段K线和新闻。

### 8.8 评价：同时回答发现得早、买得合理、亏损可控

两只作为回归样本，不用于拟合参数。优先恢复同一早期推荐批次全部股票，包含亏损、移除、已卖出与未买入项；找不到旧批次就标未知，不能拿当前12只持仓当完整推荐样本。当前其余10只合计浮亏15,391元必须保留为账户背景，而非被两个赢家覆盖。

| 评价层 | 指标与限制 |
| --- | --- |
| 发现能力 | 固定候选队列的首次发现至1/5/10/20日表现、发现至许可延迟、未入选原因；同时统计无效候选占比及持续观察成本 |
| 入场质量 | 冻结许可/触发后、合法成交后的收益分别统计；MAE、早期跌幅、隔夜跳空、止损后风险、买不到比例 |
| 趋势捕获 | 固定窗口的收益与持有路径；提前结束的代价、重新入场损益及成本；不以事后最高价算可实现利润 |
| 组合结果 | 同资金/预算下扣费收益、最大回撤、最差10%表现、行业集中、成交率与空仓比例 |
| 稳健性 | 排除最大两个赢家后的结果、同阶段亏损对照、月份/市场状态分层；不将跨标签同股视为独立样本 |

预先锁定观察窗口与路线，不用最终上涨多少定义事前赢家。推荐时间缺失的两案例只能计算“买入后表现”，不能计算“推荐后表现”；事后公开证据重建与当时真实采集回放分表。收益未成熟时保持pending，不记0或用当前数据提前结算。

按时间向前验证，并隔离重叠持有窗口；至少20个新交易日和每路线30个成熟episode才出首轮评估，中长线未成熟继续等，不把最低覆盖当有效性证明。改善仅靠这两只、负尾变差、成本压力后消失或多数组合空仓时不晋级。正式切换需完整对照报告与确认，不承诺收益改善已经实现。
