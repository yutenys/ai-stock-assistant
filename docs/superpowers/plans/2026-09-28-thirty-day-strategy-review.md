## 1. 核心结论

1. **收益偏弱有实际数据支持。** 近30天加入收藏的96条记录，当前参考收益均值-2.39%、中位数-4.76%，仅34.4%为正。短线组42条均值-6.12%。
2. **市场风控存在可复现的优先级问题。** `classifyMarketRegime` 先判断局部强势，再判断风险释放。即使全市场仅16.46%的涨跌家数中为上涨，只增加一个强势板块就能把 `riskOff` 从true变false。不是简单的阈值调优。
3. **入选后的管理缺失同样重要。** 同一批83条收藏从09-22均值+1.94%变为09-28的-2.07%，20条由盈转亏。继续堆叠选股因子不能替代失效、退出与盈利保护规则。
4. **历史效果反馈没有真正接通有效数据。** 前端只传入 `outcomeOrigin:'favorite'`，主进程默认排除收藏，最新日志 `sampleSize=0`、`excludedCount=138`。排除选择偏差是正确的，但还缺少已发布推荐/研究成交的替代输入。
5. **“持续流入”不能当永久买入理由。** 同一14条入选时标记持续流入的收藏，09-22正收益比例71.4%，今天仅21.4%。需要跟踪入选后资金和价格的转弱，而不是只保留入选标签。
6. **不是全面放宽数量。** 09-24末次记录已有A=5、B=11；A里严格仅1、观察4。应增加合格候选覆盖，并优先降低无效追强，不保证每天必须推荐若干只。

## 3. 优化设计

### P0：市场防守与评价链路先落地

**市场风险与局部机会分开表达。** 保留 `marketRegime`，新增/明确独立 `riskLevel`、`allowNewEntry` 和 `localized`，不是只交换文案。

- 风险释放优先于局部强势：`riskRelease=true` 时 `riskOff=true` 不得被任何板块覆盖；A/B观察照常显示，暂停升级为可研究新入场。
- 普跌但非风险释放：局部机会只进入观察，等待市场广度与对应板块同时恢复；避免全局一刀切，也不把局部强势等同普涨。
- 恢复使用两个不同市场快照确认，盘中至少间隔15分钟且 `snapshotId`/`quoteObservedAt`不同；同一缓存刷新不算两次。该间隔作为初始研究参数，验证后再决定。
- 新闻、外盘积极只可辅助，不得越过本地广度、可交易性和公司硬风险；同样不能让普通海外负面标题无差别否决全市场。

**建立真正可用的评价闭环。** 保留收藏排除约定，不通过开启 `includeFavorites` 来伪装修复。

- 已发布推荐成为主评价输入；已成交研究账户成为交易收益输入；收藏仅作旁路诊断。
- `publishedAt`可信、版本明确、信号可识别才进入正式统计；旧 `generatedAt`、回填、历史待筛池单列。
- 固定1/3/5/10/20/60交易日观察窗口，另存T+1实际可卖收益；不把不同持有天数累计涨幅混在一起加减分。
- 同一股票/策略/周期的未结束观察合并为一个episode；持续刷新只追加状态，不新增独立绩效样本；形态失效后重新确认才能开新episode。
- 字段至少保留 `signalId/batchId/episodeId/code/track/strategyId/modelVersion/publishedAt/inputCutoffAt/horizon/entryPolicy/entryAt/entryPrice/exitAt/exitPrice/fees/status/exclusionReason`。
- 接通后先只显示评价，关闭未通过样本外验证的自动权重修正；不是立刻把亏损标签全降权或大涨标签全加权。

### P1：板块轮动从“排名”改为“阶段和转移”

复用 `assessSectorCapitalTrend`、`classifySectorRotationPhase`、`annotateSectorRotation`，不另建平行评分体系。

1. **统一口径。** 同一来源、分类层级、交易日/时段比较；保留成分版本。行业主表排序，概念只作附加主题；重叠成分暴露合并评估。
2. **识别方向。** 分别保留当日/3日/5日/10日净额、净额占比、名次变化、板块相对指数强度；滚动窗口不相加，“累计为正”不等于“逐日连续流入”。
3. **识别增减速。** 资金排名上升但板块/龙头价格滞涨，标记分歧；资金峰值回撤、上涨家数下降、龙头转弱，标记退潮。不能只看当日净流入仍为正。
4. **识别扩散。** 涨跌中位数、站上MA20比例、前3大成交/流入占比、有效成分数一起看。成员不足10的板块按低置信度，不与百股板块的“100%上涨”直接比较。
5. **保留状态。** `观察回流 → 扩散确认 → 持续但未拥挤 → 拥挤分歧 → 退潮`；每次变化列出新增/失效证据。缺失关键资金只显示观察，不填中性分冒充核验成功。
6. **区分资金轮动和避险。** 例如电力单日回流但10日流出，应显示防御回流待确认，不直接挖掘全板块追涨；市场风险释放时即使商用车多日流入，也不能抵消整体防守。

离线验证先比较“现有排名”与“排名+增减速+广度+拥挤+失效”两个版本。逐项消融，不一次增加大量权重，也不根据这14条亏损直接否定所有持续流入。

#### 策略边界与确定性规则

新增 `strategyId: leader-reversal-shadow`，展示名“C类破局龙头·研究观察”。A继续研究稳健轮动，B继续研究突破后的首次缩量回踩；C用于检验高位龙头分歧后恢复，不把C候选塞进B的可入场列表。同股可有多个策略证据，执行风险与总暴露仍按股票去重，禁止重复加分或模拟重复建仓。

1. **唯一最高标。** 初版只比较同一时点、同一涨跌停规则组内的连续收盘涨停高度，至少2板；当时有效池内最大高度对应且仅对应一只股票，才标“唯一最高标”。并列为“并列最高”，不满足唯一条件。缺成员或池覆盖无法确认则为“最高标待核验”，不能在已筛剩的少数股票中选第一名冒充全市场唯一。主题最高标单列，不冒称全市场最高；规则分组使用按日期生效的交易规则，不能只按代码猜测。
2. **破局。** 单纯最高不等于突破市场高度压制。以此前10个交易日同组已确认连板高度上限为冻结参照（不含信号日），当日确认高度超过该值时增加“高度破局”证据；比较5/10/20日窗口稳定性，不事后改参照。缺少完整历史则仅观察，不能冠以确认破局。昨日龙头停牌、跌停或失联不能自动把次高标升级为已确认破局。
3. **爆量。** 使用完整日成交量/此前20个交易日有效日量均值，分母不含当日，基准期少于15个有效观察或存在未处理除权/口径异常则缺失。1.5–4倍仍属现有正常放量；>4倍仅标极端量能研究证据，不提供买入许可。截图没有爆量阈值，初版将>4倍作为待检验分桶，不能宣称已复现原策略。分别记录换手率、成交额及历史分位；盘中同时间量比单列，不与日量比混算。
4. **弱转强。** 必须有先弱后强的两个可追溯状态。日线降级版本：前日相对匹配指数收益为负，且收盘位于当日高低区间下半部（振幅为0则不可判）；信号日收盘越过前日最高价、相对指数收益转正，并满足有效量能证据。盘中版本另需按时间排序的分时记录、冻结恢复价和两次间隔至少5分钟的独立快照确认；禁止用收盘高点反标早盘已转强。没有分时数据只能标“日线弱转强候选”，不能声称已确认回封、竞价抢筹或炸板修复。
5. **确认与失效。** 数据完整且上述证据成立仍为影子信号。缺数据为待核验；价格跌破冻结失效位、原唯一高度关系不成立、量价分歧加剧或市场风险释放时保留失效原因和证据时间。量能异常、不可成交与策略失效分别记录，不能把未成交删除以美化收益。状态恢复需新的证据，不修改原episode结论。

这些数值均为预注册研究参数。严格C样本需要爆量、弱转强、唯一最高标和高度破局同时满足；缺任一项归为未确认，不以其他高分补足。日线代理和分时确认分开统计，不能混合报告胜率。

**避免连续涨停与“前日下跌”条件互相排斥：** 上述日线代理只发现一般弱转强候选，不用作连续涨停龙头的必备前置条件。严格C采用信号日内“分歧→恢复”的分时路径：以前一交易日已确认的连板高度建立候选池，记录当日曾打开涨停且价格低于冻结恢复价的弱状态，再记录重新站上恢复价的两次确认；恢复价初版取当日有效涨停价，来源必须可核验。日终再判断本日连续板数、唯一最高、高度破局与完整日爆量，首次确认时间不得早于最后一项证据可用时间。未封回仅保留修复观察；一字板没有可证实弱状态时不算弱转强。收盘才新增的严格C不得回填为早盘信号。

初始失效位使用当日弱状态开始至第一次恢复确认前的分歧区间最低价，按有效价格档位冻结；缺少分时低点时不生成严格C入场计划。盘中暂时跌破但日终恢复不删除已发生的失效记录；新episode仍须重新走完整确认流程。不同涨停规则组的最高标标签必须同时显示范围，例如“10%规则组唯一最高”，不能省略范围而造成全市场最高的误解。

#### 情绪周期与板块周期分离

复用市场快照，为 `sentimentPhase` 另存证据：涨跌停家数、昨日涨停股当日表现、连板晋级率、炸板率、最高高度变化及高位股亏损扩散。指标分母包括当时可见的失败者，不只保留今日晋级股；保存覆盖数、有效交易日、时间与来源。

指标初版口径：涨停广度=当前确认涨停数/同规则组当时具备有效限价及行情的可交易股票数；连板晋级率=昨日收盘涨停且今日再次确认涨停数/昨日完整涨停池可核验成员数；炸板率=当日曾触及涨停但当前未封住的股票数/当日曾触及涨停股票数（非炸板次数）。昨日涨停股表现按该冻结池逐股相对前收盘收益等权，停牌和缺价分别计数。高位股初版为昨日连续至少3板的冻结池，亏损扩散为该池负收益家数比例进入此前20日的上四分位。分母为0、样本覆盖不足或历史分位无效均返回未知，不返回0；保存有效数/应有数，覆盖低于90%时阶段只作低置信观察，不确认转换。停牌不能默默从昨日晋级池删除；将其列为未晋级且另报数量，缺失成员则降低覆盖率。

- 初版按同规则组此前20个完整交易日分布冻结阈值，至少15日有效；每次升级保存参数版本。上/下四分位只作待验证门槛，不把截图均值当阈值。
- 发酵候选：涨停广度与晋级率较前一有效快照改善，且尚未同时处于历史上四分位。高潮候选：二者同时处于上四分位。分歧候选：炸板率进入上四分位或高位股亏损扩散，但整体广度尚未同时塌陷。退潮候选：广度、晋级率处于下四分位且昨日涨停股表现为负。非上述情况为中性/过渡。
- 裁决优先级为退潮、分歧、高潮、发酵；连续两次独立有效快照确认阶段变化。收盘研究按不同交易日比较；盘中快照使用同时间基准，不能复用完整日分位。缺关键指标返回“情绪阶段待核验”，保留已知证据，不能默认发酵或高潮。
