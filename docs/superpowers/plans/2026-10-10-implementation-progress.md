# 2026-10-10 题材双轨与报告实施记录

对应设计：`2026-10-10-theme-regime-and-portfolio-design.md`。本记录区分已经落地的代码、实测结果和仍缺证据的部分；影子状态不改变正式 v26 买入许可或收益口径。

## 已落地

- 收盘报告输入透传收藏加入时快照、全部账户持仓；盘后首次发布不计当日表现。历史手工模拟与规则模拟分账显示，缺最终收盘价标为部分估值，不拼造当日完整净值。
- 推荐评价按 1/3/5/10/20/60 日独立汇总，并提供预定义配对窗口；不因 60 日尚未成熟而清空短线结果。旧大报告通过工作线程流式读取摘要，原 JSON 修订保留只读。
- 新报告将 episode 明细按内容哈希分块，报告主体保留摘要和引用。应用内分页读取每次最多 20 条并核验块哈希；浏览器报告提供同目录原始明细块链接。市场路径和板块快照在写入前压缩，旧超大缓存不在主进程同步解析。
- 题材影子状态按成员版本、真实板块资金来源/时点、去前三广度和涨停覆盖建立；同日跨源、成员变化、源时间不递增时不计算资金斜率。跨日只延续轮次，不相减当日累计净额；缺交易日快照暂停计数。推荐卡片、板块、个股详情及报告展示影子状态与缺失证据，不提升正式许可。
- 删除收藏个股或标签时保存最小移除事件，不删除模拟持仓；报告和离线审计单列这些事件，避免把当前收藏截面误当全历史。
- 报告在应用中分为每日复盘、次日预案、术语与规则；浏览器版本采用无脚本页签。结构化字典区分 `track.B`、`relay.B2`、`external.chan.B2`，外部术语不触发本地策略。
- H5–H7 使用独立的 `theme-regime-20261010-shadow-v1` 冻结清单，自首次运行后的下一交易日开始采集当时的通过/拒绝/未知决策。H5要求正式许可、同日已核验触发及双轨证据；H6使用独立的同日60分钟回踩触发；H7仅在H5和H6都通过时通过。冻结判定和60分钟计划写入发布快照，回放复用原有 T+1、费用、同资金/仓位模型，并增加同日起算的题材基线；未知证据不计成交。影子结果不参与正式评分和账户成交。
