# 最近一周推荐质量与个股分析优化设计

日期：2026-10-19。状态：工程修复已实施；Q1–Q3 影子实验已接入，前向验证待样本成熟。

## 1. 目标与结论

目标不是增加推荐数量或让历史评分变好，而是减少高位观察被误读为买点、不可执行计划长期等待、弱市隔夜损失，以及盈利持仓回吐。保留 A/B 两路入口和短线、波段、中长线标签；不新增第三套推荐引擎。

本轮以 2026-10-12 至 10-16 的五份最新收盘报告为依据。主要问题按优先级排序：

1. **先修计划闭环。** 247 条突破计划中 244 条的确认价高于最高入场价，其中 240 条仍为 armed；97 条回踩计划中 94 条的区间下限高于最高入场价。不是单纯等待行情，而是价格约束没有交集。
2. **B 组发现强势有效性与买入有效性必须分开。** 本周 B 组发布后至当日收盘平均 -0.71%；当前版本本周新建信号，下一交易日观察平均 -2.03%，三交易日平均 -3.78%。不能继续让当天涨幅和贴近日高主导“近期可执行”排序。
3. **市场由强转弱需要路径判断。** 10/16 午间上涨占比 88.68%，收盘 60.80%，回落 27.88 个百分点；收盘主状态仍允许新入场。已存在路径证据，但目前为 shadowOnly，不能把它当成已经生效的风险约束。
4. **个股趋势、当前买点、持仓处置分别输出。** 光洋仍盈利，却在本周两个报告端点之间回吐 976 元；吉华增加 390 元不能抵消组合其他亏损。
5. **先修确定性错误，再影子验证策略。** 不根据这一周直接增加吸筹权重、不放宽风控凑数量、不把资金缺失转成资金流入、不承诺优化后盈利。

## 5. 目标决策流程

```text
截止时点有效证据
  → 市场环境与盘中路径
  → 去重后的板块轮动与个股成员证据
  → A/B 候选发现（观察，不等于许可）
  → 路径特定价格可行域与风险预算
  → 已完成 K 线/资金/消息/公司风险核验
  → 当前入场许可与 T+1 模拟执行
  → 持仓独立管理、完整失败归因、收盘评估
```

趋势质量、买点成熟度、证据完整度分别显示。高趋势分不能覆盖无效买点或公司硬风险。沿用现有状态字段，增加少量 feasibility 原因，不重建一套平行状态机。

## 6. P0：修正可执行性、状态与时间口径

### 6.1 买点可行域

- 突破路径下限为确认价上方最小合法价格档；上限为真实目标支持的最高入场价、风险预算及其他价格约束的最小值。
- 回踩路径区间为原回踩区间与风险价格上限的交集。确认必须是回踩后的承接确认，不再强制突破远端历史阻力后才允许“低吸”。
- 先使用未四舍五入的数值计算，再按证券价格档位向保守方向取整；取整后再次验证交集。
- 下限高于上限、止损不低于入场、目标不高于入场、成本后空间不够时，输出 `feasibility=empty` 和具体冲突值。保持 watch，不 armed，不触发。
- 目标缺失输出 unknown，不用 ATR 外推冒充已验证阻力。已突破的阻力只有被当时证据确认转为支撑后，才可考虑下一个独立目标；不能为了通过 RR 直接跳过仍有效的近端阻力。
- 冻结计划不随价格上升抬高止损以“造出”RR；旧计划失效后须有新结构证据及新 revision，并保留旧结果。

沿用当前成本后 RR 至少 2 的基线，不以本周数据调低。明确该阈值是待验证的策略约束，不是收益保证。缺少隔夜跳空估计时只能显示压力情景，不能称为最大可能亏损。

### 6.2 状态语义

`watch → armed → allowed` 每一步均核验本路径的数据、价格交集与当前风险。blocked/expired 不自动复活；曾触发过不等于现在仍可入场。现有 triggeredAt、历史事件用于审计，currentPermission 用于按钮、排序、模拟执行；三处必须一致。

漏斗记录：发现数 → 数据可用数 → 结构成立数 → 价格可行数 → 风险通过数 → 已触发数 → 可成交数。每个未通过项保留主因与其他原因，不能只显示最终 0 只。

### 6.3 盘中、盘后与 T+1

项目模拟交易继续只覆盖既定日间交易窗口；不在本次隐式扩展到集合竞价或盘后交易产品。

- 日线突破使用完成收盘证据，下一交易日重新核验买价，不回填到当天。
- 首次回踩或 60 分钟结构使用完成的分钟确认后，若处于支持的交易窗口，可在当日评估；不得因统一 nextTradingDay(formationDate) 无条件延迟，也不得绕过形态自身最早确认时间。
- 新买数量下一交易日才进入可卖数量；盘后计划最早次交易日买、再下一交易日卖。买入延期时卖出日同步顺延，停牌/跌停不保证成交。
- 分开记录 formationAt、confirmedAt、publishedAt、earliestBuyAt、filledAt、sellableDate。收益从已核验成交开始，不从计划创建开始。

交易约束参考：[上交所交易规则 2026 修订，第 3.1.4 条](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)。本系统支持范围不代表交易所所有品种与交易机制的完整实现。

### 6.4 量能口径

保留完整日成交量/前 20 个完整日均量作为日线量能，1.5–4 倍条件仅作用于同口径确认；超过 4 倍不作为健康放量买点。盘中另存累计成交量、供应商量比定义、同时间历史累计量比及覆盖率，不互相回填。

没有同时间历史分钟量时，允许展示“累计量相对完整日均量”，但不能据早盘 0.06 倍就认定缩量洗盘、也不能外推全天量确认突破。已完成的 5 分钟量可与同类型、同交易阶段历史窗口比较；不跨午休线性外推。

## 7. P1：A/B 推荐与板块轮动

### 7.1 A：有支撑的蓄势或回踩

箱体、MA5/10/20/30/60、波动压缩、反复试压继续作结构证据，不一律要求所有均线上方。分辨“止跌修复”“趋势回踩”“底部蓄势”，同时列出失效条件。资金与消息用于佐证，不能把正净流入解释成确定吸筹。

排序优先级：证据有效 → 价格区间可行 → 支撑未破坏 → 板块承接与个股相对表现 → 成本后剩余空间 → 同主题暴露。对持续下降、支撑不断下移者保留观察但不授予低吸许可。32 条吸筹观察样本不足以直接上调权重。

### 7.2 B：强势发现与首次回踩分层

在同一 B 列表内部区分“强势观察”和“回踩待确认/可执行”，不再把涨幅第一直接放到操作优先位。观察层可以保留涨停/加速股以解释市场，但不自动转成模拟买单。

执行排序先看当前许可及计划可行性，再看首次回踩支撑、已完成量价承接、板块扩散持续性、资金一致性及剩余风险收益。当天涨幅与贴近日高只服务于强势发现，不作为无限累加的买点奖励。

候选数量不足时保留更多有明确原因的观察项，不能降低证据门槛凑可买名单。无可执行机会要说明具体原因，同时评估错过机会的成本，而不是把长期空仓作为策略成功。

### 7.3 健康滞涨标签重新定义

必要证据：真实所属主题在可比时段增强；个股相对该主题短期滞涨但支撑稳定；相对强弱未持续恶化；有修复/承接证据；真实资金没有明显背离。使用固定同成员集合、同时间和同价格口径比较，不把行业指数与任意概念混比。

缺成员或相对收益数据就显示“相对强度待核验/趋势观察”，不能仅因距阻力超过 3% 就贴健康滞涨。弱股跌得多不等于有补涨价值。

### 7.4 轮动从净流入榜转为可追溯路径

每个行业/主题保存数据源、成员版本、观察时间、资金口径、当前累计净额、可比前值、净额变化、广度、成员收益中位数和集中度。日内累计净额相减只称“该源累计净额变化”，存在供应商修订时不当作逐笔区间资金。

重点识别：持续流入且扩散、流入但集中于少数权重、价格上涨而资金衰减、资金回流但个股未修复。只有快照而无多时点/多日证据时，最多标记单日试探，不升级为持续轮动。

半导体、半导体概念、存储等重叠主题按成员交集归并风险；一只股票同属多个概念不能重复贡献分散度。跨供应商净额不相减，估算量价不冒充真实主力资金，不能从大单金额直接推断机构身份。

### 7.5 大盘由强转弱与消息

保存独立竞价、连续交易及收盘锚点，分别显示相邻变化和较开盘/午间变化。相邻快照差为零不等于全天平稳。既有窗口截断时保留峰值时间及覆盖标记，不能仅按剩余数组算全天峰值。

将“同口径广度显著收缩 + 昨涨停溢价转弱/跌停扩散 + 主线成员或资金衰减”作为路径降级假设。先影子验证，满足多项一致证据时收紧新开仓/加仓；恢复须有新的有效快照与持续性证据。不得使用收盘才知道的跌幅阻止上午信号。

消息和美股沿用可追溯事件与北京时间截止点，仅对有明确传导关系的行业修正。公告风险可否决，普通利好不能覆盖结构失效。报道时间、首次抓取时间、核验时间分别保留；缺失写未知，不等于利空或利好。本轮没有完成新闻因果归因，不能把下跌归咎于某条未核验消息。

## 8. 个股分析与持仓管理

详情按以下顺序统一读取同一决策对象，避免不同段落给出相反结论：

1. 当前状态：趋势质量、数据截止时间、短线/波段/中长线与对应有效证据。
2. 未持仓结论：允许评估/仅观察/不宜新开仓；明确触发区间、上限、失效价及缺少的条件。空可行域直接说“当前价格结构没有合格买点”，不再无限“等待突破”。
3. 持仓结论：成本、可卖数量、实际浮盈亏、持仓后峰值回吐、结构变化、主题风险、下一可卖时间。新买禁售和旧仓可卖分开。
4. 资金：逐日明细覆盖、真实多日汇总、当前快照分别列示；仅有汇总不能计算连续流入天数。全历史资金仍无可靠覆盖时不阻塞所有分析，也不假装数据齐全。
5. 情景与反证：结构保持、修复确认、跌破失效三种条件，以及对应的观察/风险处置。止损为条件不是保证成交价，T+1 隔夜风险单列。

盈利仓：保护线基于已冻结结构和实际可卖数量，跟踪最大有利波动及回吐，不能只因为仍盈利就继续持有。亏损仓：重新评估结构失效，不移动原止损“等解套”，不因成本高就自动补仓。新证据产生重新入场机会时建立新计划，旧交易损失仍保留。

收藏作为意向集合，模拟账户作为真实账务事实。全部收藏都可参与当前风险扫描；按版本评估只使用能追溯原始计划的收藏。未知版本、历史手工添加、已删除收藏各自保留，不删除亏损样本。

## 9. 验证与晋级

### 9.1 先修工程一致性，再验证收益

P0 可行域、错误口径、时点和状态不一致属于工程修复，用确定性测试验证即可，不需等待市场证明。P1 排序/路径门控属于策略假设，默认影子，不直接替换线上收益逻辑。

只建立三个小实验，复用现有 strategy-experiments：

- H1：B 组从涨幅优先改为可行买点及首次回踩优先。
- H2：市场路径与板块衰减联合降级，比较减少损失和错过收益。
- H3：新入场与持仓退出独立决策，比较回吐、最大回撤及资金占用。

本周数据为发现问题和固定回归案例的开发集，不能同时作为优化有效性的验收集。保留旧评分作基线；冻结版本、参数、信号与证据后，使用未参与调参的后续交易日作前向验证。已有 20 个交易日/每路线 30 个独立事件的最低要求继续执行，达标也不代表统计上已经充分。

### 9.2 评价面板

- 发布观察：当日、1/3/5/10/20/60 交易日；每列列出有效、缺失、未成熟数。
- 核验成交：实际可成交时间/价格、费用、滑点、涨跌停、停牌、T+1、现金和单主题暴露；日线同时触及止盈止损但无分钟顺序时用保守规则并标注。
- 反事实次日开盘单列，不能当实际成交；午间/盘后信号不得按此前开盘价入场。
- 路径分解：发布至当日收盘、收盘至下一开盘、下一开盘至收盘；开盘数据不全则缺失，不能用两个收盘反推。
- 指标：中位净收益、胜率、最差 10% 均值、最大回撤、MAE/MFE、收益回吐、换手、有效暴露、空仓时长、机会损失和数据覆盖率。
- 以信号生成时已冻结的同主题/同市场基准衡量超额。按日期与主题聚类报告不确定性；同股多标签、多次刷新不当独立样本，重叠持有窗口需隔离。

晋级前要求：时点和成交核验通过；成本后期望及中位表现不靠少数极端赢家支撑；尾部风险不劣于基线；非零有效执行与覆盖能解释。去除最大赢家、保留失败样本、合理成本压力后仍需检验。结果不确定则维持影子，不宣称收益改善。
