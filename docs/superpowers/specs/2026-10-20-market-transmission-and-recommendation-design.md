## 1. 本轮结论

当前优先级不是再增加一组指标或放宽评分，而是打通以下链路：

```text
截止时点可用证据
  → 市场路径与资金主线
  → 主线成分覆盖及公司业务关联
  → A/B 发现候选
  → 路径特定结构确认、价格可行域与公司风险
  → 当前许可与 T+1 执行
  → 独立持仓管理及分层归因
```

本次发现：

1. **展示与执行语义仍不一致。** 当前 A 组 3 只、B 组 2 只全部为 `watch`，买点区间全部无交集；覆盖统计仍显示 `strictQualified=3`。新可行性保护已经生效，但旧推荐数量口径没有闭环。
2. **计划生成仍可能产生结构性矛盾。** 突破确认价可能与第一目标使用同一个阻力；回踩确认价仍可能取远端突破位。下游正确拦截，并不等于上游已生成合理计划。
3. **资金主线的数据补齐存在偏置。** 成分抓取优先净流入占比和阶段趋势，20 个名额中出现 2–3 只股票的小板块；部分大额流入主线没有成分广度。缺数据不应被误读为没有主线，也不应自动成为买入理由。
4. **消息相关性和语义存在可复现误判。** “跑赢大盘”美股研报被当作 A 股市场消息；“尼日利亚央行”命中“央行”；“逆回购”命中公司“回购”利好；监管制度和公司处罚风险没有充分区分。
5. **收益改善尚无执行证据。** 今天 A/B 观察均值为正，但 B 中位数为负，移除最大收益样本后平均为负。昨天报告累计核验成交仍为 0，不能把观察收益当作可实现收益。

不承诺优化后盈利。不因当天上涨方向修改历史推荐、不抬高目标价格制造收益空间、不靠降低风控凑数量。

### 4.2 新闻处理的确定性问题

`isMarketWideNews` 仅凭“大盘”“央行”等宽泛词匹配，使美股评级“跑赢大盘”和尼日利亚央行消息进入市场域。`summarizeNews` 在无个股主体时将相关性设为 1，再按“获批”“回购”“风险”等词打分。

当前 `decisionItems` 还出现：

- “逆回购”因包含“回购”获得 +1.8；
- 多主题盘前要闻被作为一条事件，包含“风险”“处罚”等词后整体扣分；
- 市场域按“日期+正负号”压缩事件，使同日多个不同产业催化互相覆盖；
- 无可靠消息时文案仍为“按中性处理”，没有区分“有效中性”和“缺证据”。

优化不能仅补一个尼日利亚黑名单。要先识别主体、地区、事件类型、作用范围，再判断方向。

## 6. P0：先修正确性，不改收益阈值

### 6.1 统一推荐资格、观察资格和计数

同一份 `planState` 驱动大盘、详情、收藏评分解释、报告及模拟入口：

- `allowed`：满足全部当前条件，处于支持的交易窗口；仍需订单成交校验。
- `armed`：计划价格可行且证据通过，等待本路径最后触发；不叫“已经可以买”。
- `watch`：观察；必须显示数据缺失、价格无交集、未确认等主要原因。
- `blocked/expired`：失效/过期，不能展示成新的买点。

强势发现数量、待确认计划数、当前可执行数分别统计。`strictQualified` 不再仅以 `recommendationTier` 排除两个观察文本计算。当前快照预期显示“发现5，价格可行0，可执行0”，不是“严格推荐3”。

收藏不删除、不自动卖出；加入收藏只保存观察对象，不能自动升级交易权限。保留用户现有标签和多标签关系。

### 6.2 计划生成与验证必须使用同一交易结构

当前 `buildTradePlan` 的 `confirmationPrice=max(resistance,ma20,ma10)` 与最近上方阻力目标可能冲突。设计改为：

1. 明确路径是箱体突破、趋势回踩还是首次回踩；使用现有路径类型，不另建状态机。
2. **突破：** 触发位来自待突破结构。该位置突破后不能同时作为正收益目标；须有在截止时点已知、独立且更高的结构阻力。没有目标时仍为 unknown，不拿ATR外推或新高预测冒充目标。
3. **回踩：** 确认来自回踩后已完成K线的局部承接，不强制站上远端历史高点。确认价、止损、目标和入场区间必须来自同一结构时点。
4. 继续保持成本后RR至少2及结构止损约束，先求价格交集，再判断当前价是否落入。只换显示文案不能解决无交集。
5. “目标选错/确认位混用”的工程错误与“市场确实没有足够空间”的有效拒绝分开统计；后者不强行修成可买。
6. 旧计划价格与收益不追溯修改。只有出现新结构证据，按原状态机保留旧计划并生成新版本；未触发观察不能每次刷新重置首发价，持仓计划更不能被重建覆盖。

例：爱美客最新报价98.88，仍引用10/15旧计划目标95.33、入场上限92.19。应说明“旧计划已不适用于当前入场，等待新结构”，而不是继续展示旧目标作为当前获利空间。新目标必须重新取证。

### 6.3 消息域与时间校验

沿用现有事件生命周期，补足必要字段：

`entity / region / eventType / scope / publishedAt / firstSeenAt / effectiveAt / dataDate / source / link / evidenceStatus / affectedSubjects`。

| 行业/主营 | 公司主要业务和产业链位置 | 根据可靠公司资料更新；不随当天涨停改成机器人行业 |
| 概念成员 | 数据源定义的多标签归属 | 允许同时属于多个概念，保留来源及成员版本 |
| 当日催化 | 在某个决策时点与行情相关的事件解释 | 按事件日期、公开时间、首次发现时间和证据更新；允许多解释和待确认 |

给候选附加轻量 `catalystEvidence`，包含 `themeId、eventId、code、relation、source、link、publishedAt、firstSeenAt、asOf、evidenceStatus、conflicts、attributionVersion`。复用新闻事件ID和板块ID，不为每条新闻创造一个主题。

- 公司公告、官方政策、可靠业务披露用于验证“业务与事件关联”；仍不能证明该事件单独造成价格上涨。
- 数据商涨停原因可提供发现线索；只有标题、没有原始原因/时间的附件摘要标记 `reported`，不能标记 `verified`。
- 主催化在证据足够时用于展示和唯一计数；多因并存时保留辅助催化，无法区分时主归因为unknown。
- 热门概念标签数量、板块规模和涨幅不得决定公司的主催化。否则“华为概念很大”会再次吞并不相干的股票。
- 来源冲突时同时展示解释、时间和差异，不让后抓到的数据无条件覆盖先前结论。

同花顺异动仅列为待验证免注册公开候选源。接口实际访问、字段、时间戳、使用限制未验证前，不承诺可接入；不可取得时保留其他来源和unknown，不靠附件手工名单凑全市场覆盖。

### 13.2 主题广度、原因覆盖、资金覆盖分开

至少保留三组不同指标：

1. **结构广度：** 已确认成员上涨/下跌、中位涨幅、容量成员表现、去除前3强股后表现；分母为该主题可比成员样本。
2. **催化广度：** 固定股票池内，经当时证据归因到某主题的股票数/该固定池总数；缺原因的股票留在分母。原因抓取覆盖率另列，不把26条已取得原因中的26条称100%市场集中。
3. **资金覆盖：** 同源、同日、同单位的有效成员资金覆盖和净额；不存在完整成员资金时，不把原概念板块总资金直接转给新催化簇。

展示主归因时每个代码只计一次，辅助归因可重复但不相加。不同来源涨停池先按证券代码对账交集/差集、交易所、ST/新股/停牌规则，不随意合并成一个更大的“真实池”。统计单位始终显示，例如“26/54个收盘涨停样本，附件归因口径”。

附件中的“机器人48.1%单极”可成为**待验证主题集中线索**，不能直接把48.1%解释为资金虹吸程度或自动提高仓位。概念板块主力净流入50.58亿与重新归因的26只股票不是天然同一集合，必须分开展示。

### 13.3 主题轮动按证据连续性跟踪

复用 `themeRegimes`、成员修订号和episode，补充分离的 `observedDays` 与 `consecutiveVerifiedDays`：

- 跨日同主题且证据连续：跟踪观察天数、有效成员净增加/退出、资金变化及其时点。
- 成员更名、供应商分类修订、主题拆分/合并：记录映射和修订原因，不直接当作“新题材第一天”或“旧题材全部消失”。
- 中间交易日缺证据：连续确认天数未知/中断；不通过累计观察次数宣称持续天数。
- 盘后新增归因只能用于之后的决策。保存旧live序列和新replay序列，两者不能拼接计算连续命中。

把附件“边缘簇转正”提炼为待验证路径：昨日已有可靠事件及成员证据 → 今日成员扩散/相对强度改善 → 资金窗口支持 → 个股本身出现可行买点。若昨日只有事后补写原因，不能称“已提前发现”。强势证据增长并不要求再创新题材，避免因“旧题材”一项就拒绝所有合理回踩；也不把它直接升为新买入规则。

### 13.4 宽度、高度、容量和可成交性四轴并列

沿用现有 `breadth / ladderTrack / capacityTrack / planState`：

- 宽度：同窗成员扩散、原因覆盖及资金覆盖。
- 高度：当前连板级别与历史最高高度分别保存；断板后重新涨停计为新的当前连板序列，但保留高位复活风险。
- 容量：在截止时点以前冻结的历史成交额骨干、其走势/资金和成员相对强弱；成交额大不等于机构入场。
- 可成交性：一字/开板、涨停价格、有效完成分钟线、盘口或成交证据、支持交易时段和T+1。

市场“宽度集中机器人、高度出现在军工小群体”是一种分离状态，不必强行判成同一主线龙头。公开源无完整封板/炸板路径时，`ladderTrack=partial`，日K无法证明“最先回封”“回封带量”或排队成交。观察名单仍可展示，但不能借这些不可核验条件生成可买标签。

A路线关注有事件关联的蓄势/回踩及同主线中未破位的相对强势股；B路线保留强势发现，执行层只研究已确认的首次承接回踩。附件的高板、回封、反包和“孤本”仅作风险/形态描述，不新增C/F第三路打板引擎。

## 14. 新增设计：风格与ETF证据、T+1持仓规则

### 14.1 小盘修复与中期下跌可以同时成立

附件所列ETF日/5日/20日收益可启发风格分析，但目前属于附件读数，未独立取得原始K线。接入时固定产品代码、复权方式、结束交易日和完整窗口；使用ETF表现时明确是代表产品，不冒称标的指数精确收益。

保留现有大盘状态，增加解释层：权重与小盘相对强弱、成长与防御相对强弱、短期修复与20/60日趋势是否一致。单日小盘普涨不能覆盖中期下降趋势，长期弱也不能完全取消短期观察。不得以附件20日回撤为依据直接修改当前短线/波段/中长线权重。

### 14.2 ETF资金可信度先于数值

最小实现为“价格/成交证据”和“一级市场份额证据”两栏，不开发一个猜测申购的模型：

1. 优先取得同基金、同日期的实际披露份额；份额变化与成交额分开。
2. 供应商只给“规模”时先核实定义：若为基金资产净值，需对应单位净值；若为份额乘收盘价的市值规模，需同日对应收盘价。定义、日期或拆分分红处理未知，拒绝反推份额。
3. “份额变化×参考净值”即使数据齐全，也只能标为估算申赎金额，不能当成实际现金净流入；端点份额差×终点价格不是逐日现金流之和。
4. 14–16交易日有数据只报实际窗口和缺失日期；完整20日统计仍为空，不滑动起点冒充完整。
5. 0可能是真实零，也可能是接口占位；依据字段说明、更新时间和交叉来源判断，不一律把0当缺失或一律当无流入。
6. `estimated/lagged/conflict/unavailable`一律不能提供资金确认加分。ETF申赎与个股大单分类方向相反时并列解释，不能人为调成一致结论。

该约束不是断言“规模除收盘价永远错误”。[上交所基金市场数据](https://etf.sse.com.cn/marketdata/)明确部分规模按收盘价计算；[上交所ETF价差说明](https://etf.sse.com.cn/fund/learning/strategy/c/5704303.shtml)也说明市价可能偏离净值。因此必须先验证具体供应商字段，不能跨口径替换。

### 14.3 持仓退出与附件短线纪律的适配

- 对已有可卖数量，可以根据预先冻结的结构失效/时间条件评估减仓；对当日新买数量，14:30未封板只记“风险触发但T+1锁定”，等待下一合法可成交窗口。
- 旧仓和当天加仓按批次分别计算可卖量，不以账户存在老仓为理由将新买全部视为可卖。
- 不把昨日收盘价统一当所有路径止损位。结构止损来自买点证据；开盘低于止损、连续跌停或无流动性时保留实际/未成交状态，不能按理想止损价结算。
- “反抽≥3%清零”“低于3%除名”属于附件规则，不能删除用户收藏、清空累计收益、把亏损持仓改为未持仓。可增加失效/复活观察说明，用户数据保留。
- 高位反包、首板、低位首次启动必须保留历史位置差异；重新涨停不抹去此前连续上涨和断板风险。

交易约束依据[上交所交易规则第3.1.4条](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)。本次仍限定项目既有A股模拟范围，不扩展ETF交易或盘后交易支持。

## 15. 修订后的实施与验收增量

### 15.1 最小实施范围

第6–10节保持为主计划；以下作为同一证据链的增量，不并行重建评分和策略平台：

| 优先级 | 位置 | 增量 |
| --- | --- | --- |
| P0 | 新闻事件及日报数据契约 | 数据分母/范围、版本、来源、冲突和不可用状态；日报/行情/收益基准不混用 |
| P1 | 成分补齐、候选上下文、`lib/theme-regime.js` | 三层分类、当日催化解释、固定池原因覆盖、成员变更与连续观察区分 |
| P1 | 现有大盘/详情/收藏区域 | 展示“行业/概念/当日催化/当前许可”及置信度；用同一结构化字段生成文案 |
| P2 | 大盘风格上下文与报告 | 固定ETF价格窗口；未核验份额仅显示缺失，不推算资金确认 |
| P2 | 模拟账户与退出回放 | 旧仓/新买可卖量、T+1风险待执行、高位复活但不重置实际成本和收益 |

附件没有提供的接口和字段先验证可取得性，再进入实现；新增数据只保存必要摘要和可追溯引用，不复制整份外部研究工具。新增字段兼容历史缺省值，报告导入内容要转义展示，不执行HTML脚本。

### 15.2 新增固定验收样例

1. 同股同时有华为、机器人、军工概念：行业不改变；当日催化只有可靠证据才确认，冲突保留，统计不重复。
2. 26/54的附件归因只能显示池内48.15%；不得变成全市场48.15%或26只同日均有资金流入。
3. 3430/1659/5221分别计算65.70%和67.40%；与本地5925样本的值不直接拼接为趋势。
4. 14:05旧分类、17:30新归因：live继续保留旧输入；replay可生成新修订但不增加历史命中。
5. 主题名称变化、成员修订或缺1个交易日：不虚构“新题材第一天”和连续资金确认。
6. 54/56/57三个涨停池无逐股可比集合时保持差异；无封板路径不生成最先回封顺序。
7. ETF规模为净资产/市值/未知三种输入分别校验；日期错位、NAV疑似别名、缺20日窗口均不得输出确定净申购。
8. 当日新买+旧仓混合，14:30触发退出：只能使用可卖数量；未成交和T+1锁定不按卖出价记账。
9. 超声电子当日+3.64%、推荐后-2.10%同时显示；日出东方15:01 B发布不计当日观察，但其早先A发布保留。
10. 35只平均+0.28%、剔除最大赢家-0.06%：显示收益集中度，不删除大赢家美化/丑化策略，不称核验交易收益。
11. 外部规则“除名/清零/全面进攻”不改变收藏、持仓成本、实际交易、仓位上限。
12. 同一阈值区间不能同时标健康和恶化；窗口、来源和版本不同则明确并列，不强行给单一结论。

### 15.3 验证不能偷看盘后分类

先修确定性口径与T+1错误，再把“当日催化取代标签堆叠的候选发现”作为单因素影子比较，复用现有实验平台。基准仍是冻结版本，不能把17:30修订标签用于10:01回放并称其为实盘预测能力。

评价同时记录：可解释主题覆盖、冲突率、未知率、主线内与主线外的固定样本表现、与同板块匹配样本的相对收益、合法计划比例、成交率及损失尾部。匹配基准在信号时点冻结；不能拿收盘后最强主题作历史推荐的基准，也不能仅凭机器人一日表现调高其权重。

本次仍未验证THS原始池、ETF逐日份额、龙虎榜或附件所称机构观点原文；这些只保留为外部报告线索。生产代码已按第6–10节和第15.1节的可验证范围落地；收藏、模拟成交和历史报告未被覆盖，未核验外部数据不参与加分。
