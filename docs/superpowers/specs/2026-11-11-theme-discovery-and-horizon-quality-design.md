# 题材发现、可执行买点与长短周期收益质量优化设计

日期：2026-11-11。状态：代码已落地并通过回归；收益验证仍为pending，F路径真实首封数据仍待公开源提供。基线：ca26ee5 / v31。

用户口径修订：以收藏中每日推荐批次的后续逐日表现作为策略优化的主要依据；模拟账户仅辅助检查功能，不作为选股效果或长期策略优劣的主要证据。以下新增第2.5节优先于原文有关评价优先级的描述。

## 1. 目标与选择

目标：改善同信息截止时点、可成交、费后、符合T+1约束的收益质量，优先减少尾部亏损，而非增加推荐数量或追求事后命中涨停。不能承诺稳定盈利。

三种方案比较：

1. 放宽现有筛选：能增加数量，但不能修复数据断链、执行评价和长线基本面缺失，不采用。
2. 直接复制截图首板打分：能发现强势题材，但截图规则不完整，存在时间穿越及无法成交问题，不直接上线。
3. **推荐：修复既有证据链，分离发现与执行，首板作为独立影子路径，长线另设基本面门槛。**复用现有策略、计划、研究账户及报告模块，不另造平台。

本设计修订11-10文档的完成口径：v31有部分实现，但“独立路线触发、真实隔夜压力、完整计划生命周期、前瞻收益闭环”不能仅凭文案修改及回归测试判定完成。后续逐项以端到端证据验收。

### 2.5 主要评价改为每日收藏推荐批次（用户修订）

**核心问题：昨天推荐并收藏的股票，今天怎么样；前几天推荐的股票，之后每天怎么样。**不能用旧模拟持仓盈亏或推荐当日收盘表现代替这个问题。观察收益无需先有触发/成交记录：即使触发样本为0，仍须评价推荐名单的后续选股质量，但不称为实际交易盈利。

本轮复核：609条收藏均有`favoriteBasePrice`和`favoriteAddedAt`，572条能通过`favoriteEntrySnapshotRef`连接`data/user-favorite-evidence.json`，其余37条缺关联证据。已连接的抽样含当时模型版本、推荐信号、评分、行业基准与计划，不能再笼统称收藏都没有原始证据。历史日K及各期限终值尚需逐股核验，不能拿当前刷新价格冒充历史收盘。

#### A. 批次与日期

- 主表按“推荐交易日 + 盘中/盘后 + 路线/模型版本 + 原收藏标签”分组；标签如`1110-盘中积极`用于导航，日期以加入时间及冻结推荐记录核对，不只解析标签名字。
- 能连接发布ledger时分别保存推荐时间、收藏时间和各自价格。收藏晚于推荐时，收藏基准收益与真实发布基准收益分列；没有发布基准不能把收藏价改称推荐价。
- 所有收藏保留审计；手工、personal、重点关注等无明确推荐来源的独立展示，不混入算法批次。证据不足仍可算收藏后价格表现，但不能硬归因某模型。
- 同股同一次推荐进多个标签：标签详情均显示，整体统计按推荐episode去重。同股跨日重新推荐可作为新批次观察，但同日重复刷新不产生新样本；跨日样本有关联，统计置信区间时不能视为完全独立。
- 后续追加到旧标签的股票按真实加入/发布时间另分子批次，不把晚加入的行情回填早期批次。已删除收藏能恢复的历史保留，不仅统计当前存续赢家。

#### B. 收益口径

设D为推荐或收藏基准所对应的交易日，P0为对应冻结基准价，C(D+k)为后续第k个交易日的有效收盘价。盘后发布从下一交易日计D+1；非交易日发布以此前最近交易日作日历锚点，明确标记非交易日发布，不将其当作当日成交。

| 字段 | 计算与用途 |
| --- | --- |
| 今日涨跌 | 今日收盘相对前交易日同口径收盘，说明今天这批股票是否走强 |
| 累计至今日 | 今日收盘/P0-1，说明加入/推荐以来结果 |
| D0 | 基准当天收盘/P0-1；盘后发布不回填为可获得收益 |
| D+1、D+2、D+3、D+5、D+10、D+20 | 各固定后续交易日收盘/P0-1，比较相同持有窗口的推荐质量 |
| 后续每日增量 | 相邻交易日收盘比值变化，识别先涨后跌、延迟启动与持续走弱 |
| 区间路径 | 同期限内收盘最大回撤、最高/最低可观察收益与首次出现日期；日内高低另标，不能当成可实现买卖点 |

除权、分红、拆并股需统一P0与历史价格口径，优先使用可核验公司行动计算总回报或一致复权链；无法对齐标记不可比，不直接用最新前复权K线除未复权收藏价。停牌不延长市场交易日计数；估值可用上次有效价并标停牌陈旧，成交仍不可用。缺失、未到期、停牌、退市分别显示，不填0、不无声删除。

例如11-10批次在11-11观察D+1；11-06批次在11-09/10/11分别观察D+1/D+2/D+3。不能把两个批次截至11-11的累计涨幅直接视为相同期限效果。

#### C. 报告主视图

第一张表为批次矩阵：批次、模型、总股票数、有效/缺失/未到期数、D+1/2/3/5/10/20均值与中位数、累计至今日。点击单元格展开个股基准价、目标日期收盘价、收益和行情来源。

第二张表为“前日及更早批次今日表现”：今日涨跌、累计收益、正收益比例、同窗口行业/市场超额、最差尾部、剔除最佳股均值；不只展示TOP10。上涨比例称价格正收益比例，不称交易胜率。

矩阵首先显示等权个股结果，汇总同时给等权批次结果，避免73只的大批次压过3只的小批次。不同周期仅比较成熟队列，列明全部分母。行业/指数收益必须匹配基准时点与结束日期；缺当时指数点位不伪造精确超额。

#### D. 由结果反推规则，而非只堆筛选条件

先在同期限下比较路线、推荐时市场状态、所属主题、资金状态、距均线/阻力、量能、发布时间、风险覆盖率与模型版本。使用冻结特征，不能用今天更新后的指标解释当时入选。

- D0好、D+1差：核验追高与次日回吐，以及盘中/盘后时点差异。
- D+1差、D+3/5转好：检验是否应归波段等待，而非直接判短线有效或无效。
- 均值好、中位数差：检查是否靠少数赢家及主题集中度，不因此提高整体推荐权重。
- 各期限都弱：定位相同环境下失败集中的规则；先提出可证伪假设，再在冻结新窗口验证，不在同批样本反复调参并宣称改善。

不能从一周D+5收益证明长期有效；中长线仍需成熟的60/120日批次。模拟账户只保留辅助功能验证，不再主导上述归因和策略调优。

#### E. 落地优先级与验收

将“收藏证据连接 + 历史收盘覆盖审计 + 批次收益矩阵”提前到P0第一项，复用`user-favorite-evidence`、`recommendation-outcomes`、`daily-report`与现有行情适配器。完成真实批次评价后，再判断哪些新增筛选假设值得实施；不先用模拟账户尾部亏损定结论。

验收必须覆盖：11-10到11-11的D+1、11-06到11-11的D+3、周末跳过、盘后发布、晚收藏、标签增量添加、跨标签去重、删除记录、除权、停牌、缺行情和未成熟样本。每个汇总可展开并复算到单股，全部数量可对账。不得因无触发记录而隐藏收藏后收益。

## 4. P0：先补数据与评价链路

### 4.1 一份证据进入所有消费者

复用现有行情/资金/成员对象，统一证券或主题ID、tradeDate、observedAt、fetchedAt、来源、单位、窗口截止时间、成员版本、完整性。页面、筛选、详情、报告使用同一版本快照。刷新抓取时间不能改变事实时间。

主题覆盖分开报告“供应商摘要覆盖”和“可逐股核验覆盖”。去前三广度从同一截止时间的有效成员报价计算，明确前三按成交额排序；缺成员不计算，成员不足4只保持不可用。行业与概念重叠只作多标签，不累计净额。

风险状态拆为未调度、排队中、失败、部分、过期、已通过、已发现风险；保留各检查项证据和时点。“已通过”仅指定义的检查集合未发现问题，不等于无风险。调度与入选候选按代码连接，昂贵查询按缺项增量处理；限并发、可取消、缓存有期限，不阻塞渲染。

资金滚动窗只有同供应商、同定义、同单位、同截止时点、同交易日序列才允许作差。逐日明细与多日汇总各自声明能力；不从汇总生成逐日流入天数，不用价格/成交量代理冒充主力流入。

### 4.2 真实阻力、风险与时效

- 阻力由已完成历史K线的确认前高/整理区上沿提供，保存形成日期、确认日期及复权口径；需要右侧确认的峰值只在确认后可用。不拿触发价、任意目标涨幅充当阻力。
- 新高无上方历史阻力标为“首阻力未知”，不能自动无限空间；保留观察，另行验证趋势退出模型后再授予资格。
- 允许入场区间必须同时满足结构下沿、触发条件与风险上限；区间为空说明当前计划不成立，不靠降低假想买价强行合格。
- 正常止损损失与隔夜跳空压力分列。现有固定0.2%成本及距离止损的计算不称为完整压力测试；压力需同类标的历史隔夜分布、涨跌停退出约束和样本量。
- 同价格但资金、量能、市场或消息发生变化也使分析过期；价格未变不是复用结论的充分条件。一次替换评分、理由、权限和时间戳，旧收藏理由保留为历史，不显示成当前结论。

### 4.3 计划与报告生命周期

复用entry-plans/recommendation-outcomes/research-account。按“证券+路线+计划episode”标识，保存发现、证据到齐、发布、触发、模拟成交、退出时间；失效/过期为终态，重新入选新建episode。交易日按上海时区及交易日历，不用UTC日期字符串计预算。

区分正常零机会、补数未完成、计算失败；正常零结果不得被旧推荐回退覆盖。刷新失败时可以展示旧列表，但显著标旧、撤销当前买入许可。并发发布串行或版本检查，避免超预算/重复发布。

报告分母固定为发现、待补、合格观察、触发、可成交、成熟退出；用原因码连接缺口而非解析中文文案。触发0必须拆为未到价、数据不足、未跟踪、权限禁止、过期等。

## 5. P1：短线与题材轮动设计

### 5.1 不同路线使用不同必要条件

| 路线 | 发现依据 | 确认依据 | 禁止混用 |
| --- | --- | --- | --- |
| R1弱势修复 | 跌势收敛、低点稳定、相对强度回升 | 收复局部结构且资金边际改善 | 不要求此前所有资金窗为正来定义反转 |
| R2趋势回踩 | 中期趋势未坏、回踩缩量、支撑有效 | 企稳后重新转强，价格仍处风险区间 | 回踩本身不强制1.5倍放量 |
| R3整理首启动 | 整理区与压缩量能可核验 | 首次有效离区，确认量温和且未透支 | 不把已涨多日的高位股重复称首启动 |
| F题材首板发现 | 新近激活题材、首板时间、同簇扩散 | 独立观察路径，次日/回封可交易证据另验 | 不等同于既有方案A/B、不直接赋买入权限 |

突破确认量1.5–4倍保留为现有对照门槛；大于4倍标爆量风险，不强制所有路线达到1.5倍。盘中量需同时间历史对比；没有同时间数据只能待确认，不能用半日累计量除全天均量。

资金分“持续流入”和“由流出转修复”：前者要求独立窗口一致，后者保存先前流出、近期改善及价格承接，不因历史负值永久拒绝修复，但只进独立影子对照，不绕过风险、可成交与空间门槛。分数排序不得抵消硬风险。

### 5.2 F路径的最小研究定义

只增加一个研究路径，不复制全套未知买点代号。初始待验证参数明确冻结：

1. 新激活主题：最近5个完整交易日未有同口径的有效激活episode；历史缺失为未知，不视为全新行业。
2. 首板：上一交易日非涨停，本日首次触及/封住涨停时间有真实来源；早封研究阈值10:00。封住与触及分字段。
3. 同簇至少3个不同证券出现同日有效首板信号，且业务关联经验证；同时保存全主题及去前三广度，缺数据不称扩散确认。
4. 最早资格时间取必要证据可知时间最大值。09:34早封、14:32才扩散，则14:32才有研究资格，不能以早封价格记收益。
5. 已封涨停只展示观察。回封/次日回踩也必须有订单之后的真实可成交证据；仅有日K不推断排队成交或盘内路径。
6. F初期与R1/R2/R3共享最多3只精选观察、每日最多5个新发布的预算，避免新增路径扩大风险；完整观察池分页，不因展示上限截断审计样本。

这些阈值是研究假设，不是截图证明的盈利规律；数据不足时F仍为待补，不用其他指标伪造首封时间。

### 5.3 轮动从静态排名改为可验证转移

复用theme-regime与现有历史快照：待验、试探回流、扩散确认、拥挤、退潮。每次转换需同源同成员独立快照；重复缓存不累计确认次数。初始研究确认间隔至少10分钟、至少2个独立快照，作为冻结参数而非既成事实。

排序同时看净流入/成交额、非重叠窗口变化、去头部广度、成员中位数、容量组与涨停梯队是否同向。容量组按盘前已知的20日成交额筛定，不能拿收盘赢家倒选。容量放量滞涨或资金退出，即使小票梯队继续上涨也不能加分放行。

政策/公告提取受益主体、产业环节、时间和反证；媒体情绪仅作弱证据。普通盘面评论超过2个交易日退出当前催化，重大事件按自身有效期处理。最终URL和事件去重；同标题不同事件不机械合并。海外信息只用当时已结束的交易时段，与国内业务映射后做背景，不能冲销公司风险。

## 6. P2：长线不再由短线高分或被套时间推导

展示周期建议：短线1–5交易日、波段5–20交易日、中长线60–120交易日，持有期是计划不是保证。周期冲突时允许多个研究标签，但每笔计划只有一个原始周期；短线亏损不能自动转长线。

中长线独立准入，所有信息按公告首次公开时间可知：

- 至少3个完整年报及8个季度可比财务序列；新股历史不足归独立观察，不能靠技术分补足。
- 收入、扣非利润及现金转换质量，负债与偿债能力、应收/存货异常、稀释与解禁、审计意见及治理风险；金融/周期行业采用对应口径，不能混比。
- 保存可验证经营论点、产业需求与竞争位置、下一财报/事件复核日；“热门题材+上涨”不是经营论点。
- 盈利为负时不用PE假称便宜；相对行业和自身历史的估值只在同口径有效样本内计算，输出情景区间，不给无根据目标价。
- 资金与周线趋势用于入场节奏及风险复核，不能替代经营质量。基本面核心项缺失即“长期证据不足”，不显示“适合长期持有”。

当前CANSLIM归一化分可继续用于已知维度描述，但明确分母、缺失维度，不跨不同覆盖率直接排名，更不能作为长线准入。长线排序先过经营/风险硬门槛，再分层比较质量、估值、趋势；不新增未经验证的大杂烩权重总分。

退出分三类：经营论点证伪、估值/收益兑现、计划时间届满复核。技术破位可触发减风险提醒，不保证按止损价成交；不随下跌移动失效条件。旧仓无原计划的，从现在建立后续管理方案，禁止回填历史“当时应该卖”。

## 7. 个股详情、收藏与账户的统一输出

每只股票展示同一结构：周期、证据截止时间、市场/主题阶段、当前结构、资金持续或修复状态、可核验催化/反证、入场区间、失效条件、首次阻力、成本与隔夜风险、下一复核条件。

结论限定为数据待补、仅观察、等待条件、研究可执行、结构失效、持仓风险复核。吸筹/洗盘只在证据满足时显示，并称结构迹象，不推断资金真实意图。优先解释为什么不能买及什么证据会改变结论。

收藏保留首次加入基准与历史来源，现价/分析另存；同股多标签不重复计组合敞口。全部收藏做描述审计，仅来源与冻结计划可核验的批次进入策略归因。先连接user-favorite-evidence及ledger，再判断证据缺失，不能仅查user-state嵌套字段。

模拟账户增加持有期、最大有利/不利变动、盈利回吐、主题重叠及费后收益；日K不足时保持未知。报告突出亏损尾部和剔除最大赢家后的结果，不只展示前十赢家。持仓行情未到收盘明确标盘中估值。

不自动卖出旧仓，不修改收藏基准或交易记录。建议仓位必须受组合风险预算与相关主题合并约束；未验证前不生成个人化固定买入金额。

## 8. 验证与上线判据

### 8.1 软件正确性验收

1. 冻结本轮89只候选输入为脱敏测试夹具，逐项区分缺数据与真实不合格；接通字段后仍允许精选0，不预设必须几只。
2. 真正执行R2反例：缩量回踩可进入等待转强，不能被公共1.5倍条件永久阻断；只改说明文字视为不通过。
3. 09:34早封、14:32扩散、缺首封却高分、炸板再回封、重复快照、混源资金窗口、成员摘要有但列表无，均有反例测试。
4. 同价资金变化使分析过期；未知交易阶段不当收盘；旧零推荐回退、跨日终态、上海日期预算、并发发布不重复。
5. 新高无阻力、复权变化、入场区间为空、T+1止损无法当天卖、跳空越止损、封板不可成交，保持正确未知/失败状态。
6. 长线财务缺失、公告晚于信号、负PE、旧短线仓被套，不能升级长期资格；多标签单股不重复计收益。
7. 单元/集成/UI全量回归，覆盖报告浏览、收藏多标签、模拟交易、排序刷新；补数任务限流可取消，主界面不阻塞。

### 8.2 收益验证

三组同宇宙、同信息截止：冻结v31、仅修数据与执行、加入分路线与轮动。F、R1、R2、R3和中长线分别报告；按日期及主题聚类统计置信区间，重复刷新不是新独立样本。

历史回放只使用当时可知数据；本周用于诊断，不再用于参数优化后宣称样本外胜出。先登记参数和成本，再滚动验证；资金分钟历史缺失的日期不能伪造完整回测。

短线至少40个前瞻交易日、100个成熟可执行episode；仅达到数量不等于通过。需费后均值及中位数为正、Profit Factor大于1、同窗口行业超额为正，并比较尾部/回撤是否恶化；成本与滑点加倍后均值仍须为正。置信区间不能支持改善时保持影子，不借新增路径凑样本。分路线样本不足单列，不借其他路线收益放行。

长线按20/60/120交易日分成熟队列及可核验基本面事件评价，120日未成熟不得宣称长线有效；20日观察不能替代长期结果。统计分红、公司行动、停牌与退出摩擦。执行胜率分母仅为成熟成交episode，缺失、未成交、未成熟分别列出。

T+1及交易制度以交易所当前适用规则为准：[上交所交易规则（2026年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)。封板买入不能假定成交，可参照[上交所有关涨停申报与成交可能性的说明](https://big5.sse.com.cn/site/cht/www.sse.com.cn/aboutus/mediacenter/conference/c/c_20160722_4146612.shtml)。订单生成后才允许记录成交；收盘确认不回填当日更早低价。
