方案二：证据硬门槛、分层发布、冻结计划、前瞻验证。推荐采用；允许空结果，会错过部分快速拉升，但可审计且不依赖猜测。

方案三：直接训练收益预测模型。当前缺稳定执行样本及完整历史分钟证据，过拟合风险高，暂不采用。

## 4. 先过滤后排序

所有条件为实验初始假设，冻结版本后检验，不以两批收藏拟合最佳阈值。

1. 数据：同交易日行情与资金、已完成历史K线、复权口径一致。盘中累计量不作全天量比；未知phase不能确认收盘。证券风险未知、关键资金缺失或过期只进入观察。
2. 市场：复用现有market gate，风险释放/禁止新入场时精选为0，不允许高技术分抵消；恢复必须满足既有连续独立快照条件。
3. 板块：复用theme-entry真实资金与剔除头部后的扩散验证；上涨不能代替净流入；成员样本不足、主题重叠、同一源时间重复均不能确认持续轮动。
4. 个股：同日真实主力净额为正，并具备同源连续观测承接证据；最近阶段明显流出不能被单日翻红覆盖。逐日数据不足不得伪称资金连续流入，降为观察。资金标签仅代表供应商交易分类，不推断机构身份。
5. 位置：已有结构失效、爆量超过4倍、接近涨停、超过冻结入场上限均不精选。允许缩量回踩，不强迫所有路线当天放量1.5倍。
6. 空间：第一目标必须来自当时已知压力，不能为满足盈亏比外推。按最高入场价、费税、双边滑点及隔夜压力退出价计算净盈亏比，初始门槛2.0；费后目标空间初始门槛3%，压力损失不超过3%。缺目标/成本不放行；这些门槛不代表预期收益或止损保证。

R1：深回撤、低点企稳、短均线收复、MACD改善全部必需；增加个股资金与板块承接，避免弱势反抽。

R2：趋势有效、真实回踩、回踩缩量、支撑有效、重新转强分别核验，不能互相替代；回踩区间量比与确认区间量比独立定义，严禁用包含拉升日的五日均量直接断定回踩缩量。

R3：保留v29同日真实资金和同周期相对强度要求；增加首次有效离开整理区事件，已有持续拉升不得每天重叫“首启动”。阶段资金衰减与冲高回落降为观察。

硬门槛通过后按费后收益风险比、压力损失、证据新鲜度、同周期板块相对强度排序；同分用稳定代码顺序。此排序不是收益概率，避免未经校准的百分比胜率显示。所有淘汰原因进入漏斗。

## 5. 发布和交易时钟

流程：发现结构 -> 观察 -> 精选待触发 -> 核验触发 -> 可执行证据 -> 失效/过期/退出。

复用entry-plans、trade-time与recommendation-outcomes，不新建第二套交易规则。短线修复保持shadow-only，样本外验收通过前不授予正式买入许可。

- 盘中发布不能以发布价假设成交，需发布后完整确认区间与可成交证据；当日买入次交易日才可卖。
- 收盘确认最早下一交易日买入，再下一交易日可卖；高开越价、涨停封单、停牌均不成交，不追价修改计划。
- 计划有效期为发布后下一个交易日结束，逾期不能复活。默认观察持有3至5个交易日，完整记录1/3/5日窗口；不把T+1前浮盈当已实现。
- 失效触发遵守T+1，跳空以实际可成交价处理，连续跌停延迟退出。价格保护不能保证最大损失。
- 分批退出按既有可验证成交与费用契约；同一日目标与止损先后未知时保守评价，不选更有利顺序。
